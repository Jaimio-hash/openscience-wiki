# Changelog · v0.28.0 {/* #changelog--v0280 */}

Erschienen September 11, 2026. Diese Version fügt Überprüfungen hinzu, die die aufgezeichnete Prozedur eines gespeicherten Ergebnisses wiederholen und die Ausgabe vergleichen. Es erweitert auch die globale Suche und macht das Laden von Remote-Medien explizit.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [Änderungen seit v0.27.0](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## Neue Features {/* #new-features */}

### Prüfen Sie, ob ein gespeichertes Ergebnis reproduziert wird {/* #check-whether-a-saved-result-reproduces */}

**Reproducibility** verwendet die Eingaben, den Ausführungssatz und die Umgebungsinformationen einer erfassten Dateiversion, um die Prozedur isoliert durchzuführen. Überprüfen Sie die erforderlichen Nachweise, bevor Sie eine Prüfung starten, und überprüfen Sie dann das Vergleichsergebnis jeder Ausgabe. Schecks können eine Version oder einen Batch von Versionen abdecken, und ihre Aufzeichnungen können exportiert werden.

Ein abgeschlossener Lauf allein bedeutet nicht, dass die Ausgaben übereinstimmen. Fehlende Beweise oder nicht unterstützte Operationen können eine Überprüfung verhindern. Diese Funktion überprüft erfasste Versionen; Es wird nicht eine ganze Sitzung wiederholt. Das Starten einer Überprüfung erfordert die Desktop-Schnittstelle, und große RDS/H5AD-Dateien werden nicht für den Inhaltsvergleich geladen. [Einzelheiten zu den Merkmalen](../guides/reproducibility.md).

### Suchen Sie Nachrichten, Dateien und Literatur zusammen {/* #search-messages-files-and-literature-together */}

Die globale Suche umfasst jetzt Projekte, Sitzungen, Nachrichtentext, hochgeladene und generierte Dateien sowie Bibliotheksaufzeichnungen und -sammlungen. Filtern Sie nach Kategorie und relevanten Feldern, wählen Sie ein Ergebnis aus, um den Kontext zu inspizieren, und öffnen Sie dann die passende Nachricht oder Datei. Unterstützte text-file-Inhalte sind durchsuchbar; Dies bedeutet nicht die Volltext-Indizierung jedes Binärformats.

Gruppierte Ergebnisse laden weitere Übereinstimmungen innerhalb jeder Kategorie. Der Detailbereich kann offen bleiben, während Sie zwischen den Ergebnissen wechseln. [Suchen ändert sich](../guides/navigation.md).

### Aktualisieren einer App-verwalteten Codex-Laufzeit {/* #update-an-app-managed-codex-runtime */}

Agenteneinstellungen unterscheiden die native Codex CLI-Version von der ACP-Adapterversion. Eine ältere App-verwaltete Installation kann ein explizites Update für das getestete Paar erhalten. Extern installierte CLIs erfordern weiterhin manuelle Wartung. Beenden oder Beenden von Aufgaben mit der Laufzeit, bevor sie ersetzt werden; Dies ist getrennt von der Aktualisierung von Open-Science selbst. [Angaben zur Laufzeitaktualisierung](../guides/frameworks.md#update-codex).

### Versuchen Sie WSL2 Bash auf Windows {/* #try-wsl2-bash-on-windows */}

Windows x64 erhält einen optionalen **WSL2 Bash Vorschau**. PowerShell bleibt standardmäßig. Die Verwendung der Vorschau erfordert eine explizite Aktivierung, das Abgleichen von Assets und erfolgreiche Bereitschaftsprüfungen. Es ist keine Voraussetzung für die gewöhnliche Windows-Nutzung. [Umfang der Vorschau](../guides/runtimes.md#wsl2-preview).

## Änderungen, die bestehende Setups betreffen {/* #changes-that-affect-existing-setups */}

| Bereich | Was zu erwarten ist |
| --- | --- |
| Fernmodellverbindungen | Remote-Endpunkte erfordern HTTPS. Bestehende Remote-HTTP-Konfigurationen bleiben editierbar, können aber nicht ausgeführt werden, bis sie korrigiert wurden. HTTP wird weiterhin für Localhost- und Loopback-Adressen unterstützt. |
| Medien in Antworten | Remote-Bilder, Audio und Video warten auf Aktivierung. Vor dem Verladen die Zielhosts inspizieren; Die Autorisierung gilt für dieses angezeigte Element. |
| Bilder, die an ein Modell gesendet werden | bei Modell-Eingabekopien wurden Nebenmetadaten entfernt; die Originaldateien bleiben erhalten. |

Diese Änderungen gelten auch beim Anzeigen oder Wiederverwenden älterer Nachrichten. [Verbindung und Medienwechsel](https://github.com/aipoch/open-science/pull/2420).

Konfigurierte Conda-, PyPI- und CRAN-Spiegel-Hosts sind vorübergehend für die Paketverwaltung autorisiert. Dies fügt keine permanenten Notebook-Berechtigungen hinzu oder autorisiert automatisch Umleitungen zu anderen Hosts. Es löst auch keinen nicht verfügbaren Spiegel oder eine ungültige DNS-Antwort. [Paketspiegel-Änderungen](../guides/network.md).
