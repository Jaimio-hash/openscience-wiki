# Changelog · v0.29.0 {/* #changelog--v0290 */}

Erschienen September 13, 2026. Diese Version fügt Skill-Entdeckung, tragbare Forschungsaufzeichnungen und lokale PDF-Figur / Tabellenextraktion hinzu. Es aktualisiert auch Codex Side Chat und externe R-Paketunterstützung.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [Änderungen seit v0.28.0](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## Neue Features {/* #new-features */}

### Entdecken und installieren Sie Skills vom Markt {/* #discover-and-install-skills-from-the-marketplace */}

Durchsuchen Sie Kategorien, Autoren und verfügbare Bewertungsdetails in **Marketplace** und installieren Sie dann ein Skill von seiner Karte. Updates erfordern eine ausdrückliche Bestätigung. Das Batch-Management unterstützt die gefilterte Auswahl, die sequentielle Installation, das Stoppen nach dem aktuellen Element und das Wiederholen von Fehlern.

Kataloge und Pakete werden mit signierten Verteilungsaufzeichnungen verglichen. Dies legt ihre Verteilungsidentität fest; es ersetzt nicht die Überprüfung der Eignung einer Methode oder die Vorbereitung ihrer Forschungsabhängigkeiten. [Angaben zum Marktplatz](../skills/marketplace.md).

### Transfer Research History in einem .science Paket {/* #transfer-research-history-in-a-science-package */}

Exportieren Sie eine Leerlaufsitzung als **.science**-Paket. **Wesentliches** ist der Standard-Exportumfang; **voll** und zusätzliche Steuerelemente können mehr Dateien, Versionen und reproduzierte Ausgaben enthalten. Importieren Sie durch ein Projektmenü, legen Sie ein Paket in ein Projekt oder öffnen Sie die zugehörige Datei, prüfen Sie dann die Vorschau und bestätigen Sie das Ziel.

Importierte Sitzungen bewahren Forschungsgeschichte und Beweise für Inspektion und Referenz. Sie sind schreibgeschützt: Ausführung und Fortsetzung sind deaktiviert. Verifizierungsaufzeichnungen, die von einer anderen Anlage erhalten wurden, bleiben die Behauptungen dieser Quelle, nicht Überprüfungen, die auf dem empfangenden Computer durchgeführt wurden. [Paketverhalten](../guides/research-packages.md).

### Extrahieren Sie Zahlen und Tabellen lokal aus einem PDF {/* #extract-figures-and-tables-from-a-pdf-locally */}

Der optionale **Figures and tables**-Workflow installiert verifizierte Modellressourcen und analysiert den PDF lokal. Öffnen Sie zwischengespeicherte Ergebnisse, kopieren oder herunterladen Sie Zahlen und exportieren Sie Tabellen als HTML, TSV oder Markdown.

Vergleichen Sie extrahierte Inhalte mit den Quellseiten, insbesondere zusammengeführte Header, Fußnoten und Inhaltskreuzungsseiten. Ungelöste Text- und Überprüfungswarnungen bleiben sichtbar; extrahierte Tabellen müssen noch vor der Analyse überprüft werden. [PDF Extraktion Details](../guides/previews.md#pdf-extraction).

### Installieren Sie Pakete in einer externen R-Umgebung {/* #install-packages-into-an-external-r-environment */}

Externe R-Umgebungen können nun die Paketinstallationszustimmung für eine vorhandene, beschreibbare persönliche R-Bibliothek erhalten. Wählen Sie eine geeignete Bibliothek aus und aktivieren Sie **Allow package install**. System- und Site-Bibliotheken sind ausgeschlossen; Die Einwilligung kann widerrufen werden.

Wenn die erforderlichen Abhängigkeitssperren vorhanden sind, können auch externe R- und Python-Umgebungen einen bedingte Paketwiederherstellungsnachweis erbringen. Die Wiederherstellung erfordert übereinstimmende Voraussetzungen und ein vom Benutzer ausgeführtes Wiederherstellungsskript. Die Restaurierung von Paketen an sich beweist nicht, dass sich die Forschungsergebnisse reproduzieren. [R Installations- und Wiederherstellungsbedingungen](../guides/runtimes.md#external-r-packages).

## Verbesserungen und Korrekturen {/* #improvements-and-fixes */}

| Bereich | Was sich geändert hat |
| --- | --- |
| Codex Side Chat | Entfernt den alten Desktop-Schutz, der den Eintrag blockierte, als der globale Anbieter ein Codex-Abonnement verwendete. Session-State- und Wiederherstellungsbedingungen können den Eintrag immer noch nicht verfügbar machen. [Details](https://github.com/aipoch/open-science/pull/2460) |
| Konnektoren | Einstellungen unterstützen Bulk-Aktivierung / Deaktivierung. Literatur Graph fügt Crossref Work / Update-Lookups und DataCite Record / Suchmethoden hinzu; Die Rfam-Sequenzsuche verwendet den reparierten Batch-Endpunkt. [Verwaltung](https://github.com/aipoch/open-science/pull/2507), [Datenmethoden](https://github.com/aipoch/open-science/pull/2509) |
| CLI und SDK | Hinzugefügt Runtime Listing / Installation, Terminal Profil Initialisierung und Codex First-Run-Setup. Diese erweitern das bestehende anwendungsgestützte CLI. [Laufzeiten](https://github.com/aipoch/open-science/pull/2489), [Initialisierung](https://github.com/aipoch/open-science/pull/2474), [Codex Setup](https://github.com/aipoch/open-science/pull/2487) |
| Aufgabendownloads | Bewahrt die Versionsidentität des Artefakts bei und repariert eine Ursache von HTTP 500, wenn Sie die Ausgabe einer abgeschlossenen Aufgabe herunterladen. [Download Fix](https://github.com/aipoch/open-science/pull/2490) |

Andere Änderungen verbessern Start, Update-Retries, Windows-Operationswiederherstellung, Literaturmetadaten und wissenschaftliche Skill-Handhabung. Siehe [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.29.0) für die vollständige Liste.
