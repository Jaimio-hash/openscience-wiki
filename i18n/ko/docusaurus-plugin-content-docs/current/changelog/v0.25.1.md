# 변경 로그 · v0.25.1 {/* #changelog--v0251 */}

Open-Science [v0.25.1](https://github.com/aipoch/open-science/releases/tag/v0.25.1)은 다음과 같은 사용자 인터페이스를 포함합니다. 현재 작동 지침을 위해 연결된 기능 가이드를 따르십시오.

## v0.25.1에서 어떤 변경 사항 {/* #what-changed-in-v0251 */}

- 보호된 노트북 커널은 Windows의 직접 샌드박스 실행 경로를 사용합니다. 네트워크 보호는 여전히 앱에 의해 표시된 한 번 관리자 설정이 필요합니다.
- 파일 및 패키지 수출 출판 atomically. 실패한 수출은 부분적으로 쓴 목적지 파일을 떠나지 않아야 합니다; 충분한 무료 공간과 매력적인 목적지로 재해.
- 생성 된 이미지 미리보기가 다시 렌더링됩니다. 이미지가 여전히 placeholder를 보여 주면 artifact 출판을 기다리며 미리보기를 다시 열고 다운로드를 fallback으로 사용합니다.
- Skills 검출 및 수리 카탈로그 일관성. 중단 된 Specialist 패키지를 교체하기 전에 모든 소스 복구 지침을 따르십시오.
- 세션 concurrency, artifact-finalization recovery, PDF 독서 정체성, Claude 사용 복구, 및 중단 된 정리는 더 탄력적입니다. 이 수정은 기록을 보존합니다; 그들은 불확실한 결과를 과학적으로 검증하지 않습니다.

나머지 부분은이 릴리스에서 사용할 수있는 기능을 요약합니다. 아래 버전 역사는 이전 소개를 식별합니다.

## 세션, 입력 및 탐색 작업 {/* #session-input-and-navigation-workflows */}

### Queue, steer 및 분지 작업 {/* #queue-steer-and-branch-work */}

턴이 실행되는 동안, 후속을 입력하고 세션 큐에 추가하십시오. Queue 행은 편집, 삭제, 재주문, 또는 즉시 보내질 수 있습니다. `Send now`은 활성 프레임 워크의 후속 채널을 사용하며 실행 차례를 취소하지 않습니다. Queued 초안은 임시이며 앱이 다시 시작될 때 손실 될 수 있으므로 다른 곳에서 중요한 지침을 유지하십시오.

`Branch in new session`을 사용하여 완료된 보조 응답을 사용하여 정확한 시점에서 계속하십시오. 지점은 선택한 응답을 통해 대화 및 활동 내역을 복사하지만 신속하게 보낼 수 없습니다. 구성 변경 배당자는 나중에 프레임 워크, 모델, 또는 reasoning-effort 변경을 확인합니다.

![긴 대화에서 마크를 실행](/img/open-science/v0.25.1/workspace-run-marks.webp)

바탕 화면에서, run-marks 레일은 눈에 보이는 사용자 프롬프트를 나타냅니다. Hover 또는 미리보기에 대한 마크를 집중하고 점프를 선택합니다. Standard Undo는 제공되는 아카이브 세션 또는 초안 변경을 복원합니다. `Cmd/Ctrl+Shift+Z`는 가장 최근 작곡가 초안 변화를 재화합니다.

### 참고 세션 및 큰 입력 {/* #reference-sessions-and-large-inputs */}

- `#`을 입력하고 세션을 선택하여 읽기 전용 가시성 문자 컨텍스트를 한 차례로 입력합니다. 결과 칩은 참조 된 세션으로 이동합니다. 참고사항은 다른 프로젝트에 접근할 수 없습니다.
- 10,000 문자 또는 300 라인 이상의 일반 텍스트 페이스트가 관리됩니다. `Show in text field`은 정확한 텍스트와 관심 사항을 복원합니다. 전송하기 전에 첨부 파일 카드를 검토합니다.
- transcript, 활동, 또는 미리보기 텍스트를 선택하여 이미지의 포인트를 입력하고 컨텍스트로 주석을 보냅니다. 그들의 근원과 일치하고 나중에 계시될 수 있습니다.
- 세션 제목 및 설명은 구성 된 모델이 그렇게 할 때 첫 번째 메시지에서 생성됩니다. 세션 컨트롤에서 수정; 수동 편집 supersede 세대.

## 파일, 종이 및 편집 가능한 artifacts {/* #files-papers-and-editable-artifacts */}

### 에이전트와 PDF 읽기 {/* #read-pdfs-with-the-agent */}

PDF 미리보기를 열고 현재 세션을 읽고 컨텍스트를 읽습니다. 최대 3개의 PDF가 연결될 수 있습니다. 에이전트는 현재 페이지를 검사 할 수 있습니다, 문서를 통해 페이지, 또는 링크 된 종이를 검색. 텍스트와 직사각형 선택은 증거 표기가됩니다; 나중에 증거를 선택하면 소스 지역을 밝혀줍니다.

선택한 모델로 전송될 수 있는 링크 용지만 있습니다. PDF 컨텍스트는 read-only 및 version-bound이지만 외부 공급자는 여전히 추출 된 콘텐츠를받을 수 있습니다. 나중에 더 이상 사용할 수 없을 때 문서에 연결할 수 없습니다.

### 텍스트 artifacts 편집 및 비교 {/* #edit-and-compare-text-artifacts */}

Markdown, 일반 텍스트, 스크립트 및 인식 소스 코드 artifacts 또는 업로드:

1. 파일 미리보기를 열고 파일 작업에서 `Edit`을 선택합니다.
2. 원본 소스를 편집하고 저장합니다.
3. 게시 할 새로운 관리 된 버전에 대한 대기, 다음 `Compare`을 사용하여 사전 검사에 대해 검사합니다.
4. 이전 버전의 Navigate 및 결과 인용하기 전에 Provenance을 검사합니다.

각 저장은 새 버전을 만듭니다; 그것은 사전 증거를 다시 작성하지 않습니다. 바이너리 문서, 이미지, 노트북 및 기타 지원되지 않은 형식은 읽기 전용 남아있다. 개정 충돌은 맹렬하게 overwriting 대신 버전 재부팅 및 비교를 보존합니다.

![Version-scoped artifact 검증](/img/open-science/v0.25.1/artifact-provenance.webp)

Agent-response HTTPS 소스는 sandboxed 사이드 미리보기에서 열립니다. 외부를 열기 전에 표시된 URL을 확인합니다. 미리보기 고립은 위험을 감소하지만 신뢰할 수있는 알려진 사이트를 만들지 않습니다.

## Notebook 및 compute 컨트롤 {/* #notebook-and-compute-controls */}

- `Variables`은 Python 또는 R 네임스페이스를 이름, 유형, 모양, 경계표로 실행합니다. 그것은 읽기 전용, 실행 후 새로 고침, 그리고 단지 검색에 대 한 커널을 시작 하지 않습니다. 터미널은 라이브 변수 이름을 제안합니다; 개인 이름은 요청하지 않는 한 숨겨져 있습니다.
- Cross-run 의존성 분석은 이전 출력 `stale`, `clear`, 또는 `unknown`를 나중에 가변 변경 후 표시합니다. rerun을 필요로 하는 `unknown`를 대우하십시오.
- 설정 → 네트워크는 Notebook에 대한 도메인 허용 목록을 관리하고 실행 시간을 계산합니다. 차단된 목적지는 `Deny`, `Allow once` 또는 `Always allow`를 요청합니다. 한 번의 승인은 정확한 명령에 적용됩니다. 경계표는 앱 실행 시간, 관련 시스템 프로세스를 다룹니다.
- 각 세션은 호스트를 컴파일하고 선택한 실행 대상을 컴파일했습니다. Composer compute 컨트롤을 사용하여 구성 된 호스트를 선택합니다. 비밀번호 인증은 운영 체제 자격 서비스를 통해 저장됩니다. SSH 키 또는 실제 에이전트를 선호합니다.
- 설정 → 실행은 커널을 배수 한 후 건강한 앱 관리 Python 또는 R 런타임을 다시 설치할 수 있습니다. 외부 해석기는 그 행동에 의해 결코 수리되지 않습니다. Agent-created-environments 스위치는 명시된 설정 또는 재설치를 차단하지 않습니다.

## 기능 및 계정 설정 {/* #capabilities-and-account-settings */}

- 설정은 메모리, 태그, Credentials 및 사용법을 포함하여 17 패널을 포함합니다. 기억은 opt-in이고 계획한; 비밀을 저장하는 것보다, 항목을 검사, 정확하거나 삭제합니다.
- 태그는 Skills, 커넥터 및 카탈로그 전반에 걸쳐 전문가를 구성합니다. 즐겨찾기는 보호되고 남아 있습니다; 다른 꼬리표는 reordered 할 수 있습니다.
- Credentials는 장치 넓은 열쇠, 접근 토큰 및 OAuth sign-ins를 저장합니다. 사용자 정의 커넥터는 일반 텍스트를 휴대용 수출로 복사하지 않고 환경 변수 또는 헤더에 credentials 이름을 바인딩합니다.
- Connector 수입품/수출은 표준 `mcpServers` JSON를 지원합니다. 수출된 비밀과 우두머리는 `${NAME}` 홀더가 됩니다. 사전 등록 된 OAuth 클라이언트는 클라이언트 ID 및 쓰기 전용 클라이언트 비밀을 받아들입니다; Issuer 또는 client ID를 변경하면 바인딩을 유효하게 합니다.
- Specialist Marketplace는 서명된 패키지를 확인합니다. 마켓플레이스 콘텐츠는 read-only입니다. 업데이트는 SemVer를 설치한 기본 라인에 대해 미리 해야 합니다. 패키지 소스 검토, 포함 Skills, 및 설치 전에 커넥터.
- 모델 설정은 메인, 서브 시약, 리뷰어, 비전 및 세션 세부 사항에 대한 시나리오 정책을 포함합니다. CodeBuddy은 Claude Code, OpenCode 및 Codex와 함께 제공됩니다. 공급자 카탈로그에는 xAI 구독, Tencent 계획, OpenCode Go/Zen 및 NVIDIA Build가 포함됩니다. 설치 된 피커의 가용성은 권한입니다.
- 사용법 패널은 공급자가 보고할 때 회전과 모형 외침을 분리하고, delegation와 같은 특성 보조 통화, 옆 잡담, 조밀함 및 회의 detail 발생. 공급 업체 telemetry는 불완전한 적용으로, 견적되지 않습니다.
