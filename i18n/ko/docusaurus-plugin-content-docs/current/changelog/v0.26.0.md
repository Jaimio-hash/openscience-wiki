# 변경 로그 · v0.26.0 {/* #changelog--v0260 */}

Open-Science [v0.26.0](https://github.com/aipoch/open-science/releases/tag/v0.26.0)은 다음과 같은 사용자 인터페이스를 포함합니다. 현재 작동 지침을 위해 연결된 기능 가이드를 따르십시오.

## Main 워크플로우 {/* #main-workflows */}

### 문학 자료 도서관 {/* #literature-reference-library */}

새로운 로컬 참조 라이브러리는 개별 PDF 및 BibTeX, RIS 또는 NBIB 레코드를 가져옵니다. 컬렉션 및 프로젝트에 대한 참조를 구성합니다. 중복 찾기; 선택된 오픈 액세스 PDF를 첨부; 그리고 개정 입증을 가진 형식 인용. Agent-discovered references는 라이브러리에 실속적으로 참여하는 Inbox를 입력합니다. [문학자료실](../guides/library.md) 참조.

### 원격 컴퓨팅을위한 Slurm 실행 {/* #slurm-execution-for-remote-compute */}

이제 각 SSH 호스트는 **Execution mode**: **Direct SSH** 또는 **Slurm**. Slurm 모드는 스케줄러 소유의 작업을 제출하고, 튼튼한 상태, 중단 후 복구, 스케줄러를 통해 취소하고, 단계별 파일을 정리합니다. 내장 **Compute 환경 설정** 기술은 설정, 수리 및 선택된 호스트에 대한 제거 지침을 생산합니다. 클러스터 관리자에게 보내거나 그(것)들을 검토하십시오.

![원격 호스트 실행 모드](/img/open-science/v0.26.0/compute-slurm-mode.png)

`sbatch`이 존재하기 때문에 Slurm을 간단히 선택하지 마십시오. 로그인 호스트 정책, 파티션/account/QoS 기본, 스크래치 경로, 모듈 또는 환경 설정, 벽 시간 제한 및 취소 규칙을 확인합니다. Open-Science은 클러스터 또는 보조 스케줄러 액세스를 제공하지 않습니다.

### 읽기 쉬운 도구 및 승인 카드 {/* #readable-tool-and-approval-cards */}

Artifact는 일반적인 노트북 통제는 원료 JSON 대신에 조밀한 요약 카드로 만듭니다. 정확한 인수, 경로, 버전 또는 실행 상태의 경우 카드를 확장합니다. Skill-load 승인 카드는 결정의 앞에 완전한 `SKILL.md`를 확장할 수 있습니다.

![Skill 문서 확장](/img/open-science/v0.26.0/skill-approval-expanded.png)

### 공급자 및 모델 카탈로그 {/* #providers-and-model-catalogs */}

Apodex는 `apodex-1.1` 및 `apodex-1.1-mini`과 내장 공급자로 제공됩니다. 번들 카탈로그에는 GPT-6 Astra 및 Claude Fable 5.1이 포함되어 있으며 지원되는 이유 제어가 있습니다. 카탈로그 항목은 credentials, 액세스, 또는 용량을 제공하지 않습니다. 설치된 피커 및 성공적인 연결 테스트는 권한입니다.

## 다른 사용자 가능 변경 사항 {/* #other-user-visible-changes */}

- **제출:** routine 읽기 전용 노트북/런타임 검사, 메모리 뷰업, 패키지 재고, 그리고 승인 계획 진행 업데이트는 더 안전한 기본 보조금이 있습니다. Grants는 설정에서 눈에 띄고 수정할 수 있습니다.
- **미리보기 메뉴:** 마우스 오른쪽 클릭 미리보기 콘텐츠를 복사 경로, 다운로드, 또는 로컬 파일을 artifact로 저장합니다. 관리된 artifacts는 입증과 반환에 context 활동을 노출할 수 있습니다.
- **작업 API:** CLI, HTTP 및 SDK 클라이언트는 세션의 모델을 검사하거나 업데이트 할 수 있으며, 노력, 메모리 설정, 그리고 프루트 - 호스트 선택은 프롬프트를 보내지 않고.
- **큰 Skills:**는 수천 개의 파일이 경계, 빠른 경로 및 패키지 무결성 검사를 유지합니다.
- **신뢰성:** 스트리밍, 장기 자원 사용, 계획 복구, 업데이트 처리, 노트북 런타임, artifact 출판, 지속, 공급자 국가, 자격 증명, 원격 액세스, 스토리지 마이그레이션 및 접근성 수신 복구 및 정정 수정.

## 작업 SDK 변경 {/* #breaking-task-sdk-change */}

레거시 세션 플랜 continuation 필드는 public Task SDK 컨트랙트에서 제거되었습니다. 클라이언트는 지원된 API를 통해 현재 세션 및 계획 상태를 읽아야 합니다. 업그레이드 전에 오래된 필드를 deserialize 테스트; 이 변화는 API 소비자, 일반 데스크탑 대화에 영향을 미칩니다.
