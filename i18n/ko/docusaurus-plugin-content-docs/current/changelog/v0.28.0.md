# 변경 로그 · v0.28.0 {/* #changelog--v0280 */}

9월 11 출시, 2026. 이 버전은 저장된 결과의 기록된 절차와 산출을 비교하는 검사를 추가합니다. 또한 글로벌 검색을 확장하고 원격 미디어 로딩을 명시합니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [v0.27.0 이후 변경](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## 새로운 기능 {/* #new-features */}

### 저장된 결과 reproduces를 검사하십시오. {/* #check-whether-a-saved-result-reproduces */}

**Reproducibility**은 캡처 된 파일 버전의 입력, 실행 기록 및 환경 정보를 사용하여 격리에서 절차를 재 실행합니다. 검사를 시작하기 전에 필요한 증거를 검사 한 다음 각 출력의 비교 결과를 검토하십시오. 체크는 1개의 버전 또는 버전의 배치를 커버할 수 있고, 그들의 기록은 수출될 수 있습니다.

완료된 실행은 혼자 출력 일치를 의미하지 않습니다. 증거 또는 지원되지 않는 작업은 검사를 방지 할 수 있습니다. 이 기능은 캡처 된 버전을 확인합니다; 전체 세션을 재생하지 않습니다. 체크를 시작하면 데스크탑 인터페이스가 필요하며 대형 RDS/H5AD 파일은 콘텐츠 비교를 위해 로드되지 않습니다. [특징 세부사항](../guides/reproducibility.md).

### 메시지를 검색, 파일 및 문학과 함께 {/* #search-messages-files-and-literature-together */}

글로벌 검색에는 프로젝트, 세션, 메시지 텍스트, 업로드 및 생성된 파일 및 라이브러리 레코드 및 수집이 포함됩니다. 카테고리 및 관련 필드에 의해 필터, 그 컨텍스트를 검사하기 위해 결과를 선택, 다음 일치하는 메시지 또는 파일을 엽니 다. 지원된 텍스트 파일 내용은 검색할 수 있습니다; 이것은 모든 바이너리 형식의 전체 텍스트 색인을 무시하지 않습니다.

그룹화 된 결과는 각 범주 내에서 더 많은 일치를로드합니다. 세부적인 팬은 당신이 결과 사이 이동하면서 열려있을 수 있습니다. [검색 변경](../guides/navigation.md).

### 앱 관리 Codex 실행 시간 업데이트 {/* #update-an-app-managed-codex-runtime */}

에이전트 설정은 ACP 어댑터 버전에서 기본 Codex CLI 버전을 구별합니다. 이전 앱 관리 설치는 테스트 쌍에 명시된 업데이트를받을 수 있습니다. 외부에 설치된 CLI는 여전히 수동 정비를 요구합니다. 종료 또는 중지 작업을 사용하여 실행 시간 전에 교체; 이것은 Open-Science 자체를 업데이트하여 분리됩니다. [Runtime 업데이트 세부 정보](../guides/frameworks.md#update-codex).

### WSL2 Bash를 Windows에서 사용해보십시오. {/* #try-wsl2-bash-on-windows */}

Windows x64는 선택적인 **WSL2 배쉬 미리보기**를 얻습니다. PowerShell은 기본적으로 남아 있습니다. 미리보기를 사용하여 명시된 활성화, 일치하는 자산 및 성공적인 읽음 체크; 정규적인 Windows 사용을 위한 prerequisite는 아닙니다. [미리보기 범위](../guides/runtimes.md#wsl2-preview).

## 기존 설정에 영향을 미치는 변화 {/* #changes-that-affect-existing-setups */}

| 영역 | 기대할 것 |
| --- | --- |
| 먼 모형 연결 | 원격 엔드포인트는 HTTPS을 요구합니다. 원격 HTTP 구성은 편집 가능하지만 수정 될 때까지 실행할 수 없습니다. HTTP은 Localhost 및 Loopback 주소로 지원됩니다. |
| 응답의 미디어 | 원격 이미지, 오디오 및 비디오는 활성화를 기다립니다. 도착하기 전에 목적지 호스트를 검사; 인증은 표시된 요소에 적용됩니다. |
| 이미지는 모델로 전송 | Model-input 사본에는 ancillary 메타데이터가 제거되었습니다; 원본 파일은 보존됩니다. |

이 변경은 이전 메시지를 보거나 재사용 할 때도 적용됩니다. [연결 및 미디어 변경](https://github.com/aipoch/open-science/pull/2420).

구성 Conda, PyPI 및 CRAN 미러 호스트는 일시적으로 패키지 관리 작업에 대한 허가. 이것은 영구 Notebook 권한을 추가하거나 다른 호스트로 리디렉션을 자동으로 승인하지 않습니다. 사용할 수없는 미러 또는 잘못된 DNS 응답을 해결하지 않습니다. [패키지 미러 변경](../guides/network.md).
