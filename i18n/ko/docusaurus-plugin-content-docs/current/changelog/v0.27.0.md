# 변경 로그 · v0.27.0 {/* #changelog--v0270 */}

이 릴리스는 문학 가져 오기를 확장하고 배경 실행을 추가하고 연구 세션에서 복구를 향상시킵니다. 또한 CLI 및 SDK 사용자에 대한 응용 프로그램 필요 Skills을 활성화하고 Connector 관리를 추가합니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.27.0) · [v0.26.0 이후 변경](https://github.com/aipoch/open-science/compare/v0.26.0...v0.27.0)

## 새로운 기능 {/* #new-features */}

### 여러 PDF를 함께 가져 오기 {/* #import-several-pdfs-together */}

여러 PDF를 선택하면 파일 선택, 대상 요약, 식별자 - 매치 정책, 진행 및 파일 결과와 하나의 가져오기 대화 상자를 엽니다. **Stop**는 더 가공을 끝냅니다; **Retry unfinished**은 미완성 선택들을 재개합니다. 단일 PDF 선택은 metadata-editor 경로를 유지합니다.

일치하는 참고를 재사용하는지, 별도의 레코드를 유지하거나 빈 필드를 채우지 않도록하십시오. 라이브러리는 독립적으로 검색 필터의 전체를 보여 주며 검출 된 DOI에서 메타 데이터를 풍부하게 할 수 있습니다. 추출된 제목과 식별자를 확인: 완료된 수입은 올바른 메타데이터를 보장하지 않습니다. [문학 도서관 및 인용](../guides/library.md) 참조.

![2개의 PRISMA 종이로 일괄 PDF 수입품](/img/open-science/v0.27.0/02-pdf-batch-ready.webp)

### 작업이 실행되는 동안 계속 작업 {/* #continue-working-while-tasks-run */}

지원된 Python, R, 지속적인 REPL 및 포탄 일은 배경에서 달릴 수 있습니다. 세션은 작업 정체성, 상태, 탈출 시간 및 취소를 추적합니다. **Open**은 해당 실행에 반환합니다. 결과는 로컬 실행 및 원격 컴퓨터 작업에 대한 대화에 자동으로 전달될 수 있습니다.

완료 후 저장된 파일을 검사합니다. 원격 작업은 여전히 구성 된 호스트 및 적절한 리소스가 필요합니다. [백그라운드 작업](../guides/notebook.md#background-tasks-and-result-delivery) 참조.

![현지 배경 작업 완료](/img/open-science/v0.27.0/13-background-task-completed.webp)

### 응용 프로그램 Skills을 사용할 수 있습니다 {/* #keep-application-skills-available */}

**Customize**, **환경 및 패키지**, **원격 컴퓨터 (SSH)** 및 **Compute 환경 설정**가 활성화되었습니다. 그들의 체크, 비활성화 스위치는 왜 그들은 꺼지지 않는지 설명합니다. 내부 지원 Skills는 또한 유효합니다 남아 있습니다; 그들은 디렉토리에 추가 공공 방법이 없습니다.

이것은 과학적 의존성 또는 Specialist에 대한 권한을 부여하지 않습니다. [필수 Skills](../skills/overview.md#why-some-switches-cannot-be-turned-off)과 [Skill 만들기](../skills/create.md)을 참조하여 저장 작업 흐름을 찾습니다.

### scripts의 통합 관리 {/* #manage-integrations-from-scripts */}

CLI 및 Task SDK은 Connector 발견, 검사 및 활성화 / 비활성화 제어, 사용자 정의 Connector 관리와 함께. Headless Linux은 OS credential vault가 사용할 수 없을 때 명시된 파일 기반 자격 증명 옵션을 얻습니다. OS 저장은 기본적으로 남아 있습니다. 파일 저장소는 암호화되지 않고 파일 시스템 액세스 제어를 통해 보호해야합니다.

[Connector CLI 명령](../reference/cli.md#manage-connectors-and-credentials), [SDK 방법](../reference/api.md#connector-management-methods) 및 [Linux 자격 저장](../reference/server.md#credential-storage-on-headless-linux)를 참조하십시오.

## 호환성 및 알려진 문제 {/* #compatibility-and-known-issues */}

릴리스에는 [#2394](https://github.com/aipoch/open-science/pull/2394), Codex 구독 Side Chat 시작을 수정하고 백엔드에서 이력서가 포함되어 있습니다. 동일한 태그 데스크탑 코드는 공급자가 메뉴 항목을 비활성화하는 데 갖는다; 그 소스 내장 데스크탑의 신선한 체크는 여전히이 가드에 도달했습니다. 조사를 요구하는 UI/backend discrepancy 및 end-to-end 검증으로 이것을 추적하십시오. [Side Chat 가용성](../guides/delegation.md) 참조.

이 데스크톱 항목 감시는 [v0.29.0](./v0.29.0.md)에서 제거되었습니다; 위에서 설명한 제한은 v0.27.0 소스에 속합니다.

설치 또는 업데이트를 위해 [설치 및 업데이트](../guides/installation.md)을 참조하십시오. 초기 변경은 [v0.26.0](./v0.26.0.md)에 남아 있습니다.
