# 변경 로그 · v0.29.0 {/* #changelog--v0290 */}

9월 13 출시, 2026. 이 버전은 Skill 발견, 휴대용 연구 기록 및 국부적으로 PDF 그림/테이블 추출을 추가합니다. 또한 Codex Side Chat 및 외부 R 패키지 지원을 업데이트합니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [v0.28.0 이후 변경](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## 새로운 기능 {/* #new-features */}

### 시장에서 Skills을 발견하고 설치하십시오. {/* #discover-and-install-skills-from-the-marketplace */}

검색 카테고리, 저자 및 **Marketplace**에서 유효한 평가 세부 사항, 그 카드에서 Skill을 설치. 업데이트는 명시된 확인을 요구합니다. 배치 관리는 필터링 선택, 순차적 설치, 현재 항목 및 재시동 실패 후 중지를 지원합니다.

카탈로그 및 패키지는 서명된 배포 레코드에 대해 확인됩니다. 이것은 그들의 배급 ID를 설치합니다; 그것은 방법의 적합성을 검사하거나 연구 의존성을 준비하지 않습니다. [Marketplace 세부 정보](../skills/marketplace.md).

### .science 패키지의 연구 역사를 전송 {/* #transfer-research-history-in-a-science-package */}

**.science** 패키지로 유휴 세션을 내보내세요. **....**는 기본 수출 범위입니다; **뚱 베어** 및 추가 컨트롤은 더 많은 파일, 버전 및 재생 출력을 포함 할 수 있습니다. 프로젝트 메뉴를 통해 가져 오기, 프로젝트로 패키지를 드롭하거나 관련 파일을 열고 미리보기를 검사하고 목적지를 확인합니다.

수입된 회의는 검사와 참고를 위한 연구 역사 그리고 증거를 보존합니다. 그들은 읽기 전용 : 실행 및 연속은 비활성화됩니다. 다른 설치에서받은 검증 기록은 소스의 주장을 유지, 수신 컴퓨터에 수행하지 검사. [패키지 행동](../guides/research-packages.md).

### PDF 로컬에서 그림과 테이블을 추출 {/* #extract-figures-and-tables-from-a-pdf-locally */}

선택 **Figures and tables** 워크플로우는 검증된 모델 리소스를 설치하고 PDF 로컬로 분석합니다. 폐열 결과, 복사 또는 다운로드 수치 및 HTML, TSV 또는 Markdown으로 내보내기 테이블을 엽니다.

소스 페이지와 추출된 내용 비교, 특히 합병된 헤더, footnotes and content crossing pages. 해결 된 텍스트 및 리뷰 경고는 눈에 남아있다; 추출 테이블은 여전히 분석하기 전에 검사해야합니다. [PDF 추출 세부 사항](../guides/previews.md#pdf-extraction).

### 외부 R 환경에 패키지 설치 {/* #install-packages-into-an-external-r-environment */}

외부 R 환경은 이제 기존의 writable Personal R 라이브러리에 패키지 설치 동의를받을 수 있습니다. 자격이 된 라이브러리를 선택하고 **Allow package install**을 활성화하십시오. 시스템 및 사이트 라이브러리는 제외됩니다; 동의는 개정될 수 있습니다.

필요한 의존성 잠금이 존재하는 곳에, 외부 R 및 Python 환경은 또한 조건부 패키지-restoration 증거를 제공 할 수 있습니다. 복원은 prerequisites 및 user-run 복원 스크립트와 일치해야합니다. 나머지 패키지는 자체가 연구 결과 reproduce를 증명하지 않습니다. [R 설치 및 복원 조건](../guides/runtimes.md#external-r-packages).

## 개선 및 수정 {/* #improvements-and-fixes */}

| 영역 | 자주 묻는 질문 |
| --- | --- |
| Codex Side Chat | 글로벌 공급자가 Codex 구독을 사용했을 때 입력을 차단한 오래된 데스크탑 가드를 제거했습니다. 세션 상태 및 복구 조건은 여전히 사용할 수없는 항목을 만들 수 있습니다. [세부정보](https://github.com/aipoch/open-science/pull/2460) |
| 커넥터 | 설정은 대량 활성화 / 비활성화를 지원합니다. 문학 그래프는 Crossref 작업 / 업데이트 조회 및 DataCite 레코드 / 검색 방법을 추가합니다. Rfam 순서 수색은 수선 배치 엔드포인트를 사용합니다. [회사연혁](https://github.com/aipoch/open-science/pull/2507), [데이터 방법](https://github.com/aipoch/open-science/pull/2509) |
| CLI 및 SDK | runtime listing/installation, 터미널 프로파일 초기화 및 Codex 첫 실행 설정 추가. 이들은 기존 애플리케이션 백업 CLI을 확장합니다. [런타임](https://github.com/aipoch/open-science/pull/2489), [초기화](https://github.com/aipoch/open-science/pull/2474), [Codex 설정](https://github.com/aipoch/open-science/pull/2487) |
| 작업 다운로드 | artifact의 버전 정체성을 보존하고 완료된 작업의 출력을 다운로드할 때 HTTP 500의 원인을 수리합니다. [다운로드 수정](https://github.com/aipoch/open-science/pull/2490) |

다른 변화는 시작, 갱신 화물, Windows 가동 회복, 문학 메타데이터 및 과학적인 Skill 취급을 개량합니다. 전체 목록의 [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.29.0) 참조.

임명을 위해, [설치 및 업데이트](../guides/installation.md)를 보십시오. 초기 변경은 [v0.28.0](./v0.28.0.md)에 남아 있습니다.
