# 更新日志 · v0.27.0

本次更新扩展了文献导入能力，加入后台执行，并改进研究会话的恢复处理。应用必需的 Skills 保持启用，CLI 与 SDK 也增加了 Connector 管理能力。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.27.0) · [与 v0.26.0 的完整差异](https://github.com/aipoch/open-science/compare/v0.26.0...v0.27.0)

## 新增功能

### 批量导入 PDF

选择多份 PDF 后，在同一个导入窗口检查文件选择、目标位置、标识符匹配策略、进度和逐文件结果。**Stop** 停止后续处理，**Retry unfinished** 重试尚未完成的选中项。只选择一份 PDF 时，仍进入元数据编辑器。

遇到相同标识符时，可选择复用已有文献、保留独立条目或补充空字段。文献库总数独立于搜索筛选显示，并可根据识别出的 DOI 补充元数据。导入完成后仍需检查标题与标识符；完成状态不保证元数据准确。详见[文献库与引用](../guides/library.md)。

![两份 PRISMA 论文的批量 PDF 导入](/img/open-science/v0.27.0/02-pdf-batch-ready.png)

### 将长任务放到后台执行

适用的 Python、R、持久 REPL 和 Shell 工作可在后台运行。会话跟踪任务身份、状态、耗时和取消操作；**Open** 打开对应执行记录。本地运行和远程 Compute 作业的结果可自动送回对话。

完成后应检查实际保存的文件。远程作业仍需配置主机并具备合适资源，详见[后台任务](../guides/notebook.md#后台任务与结果送达)。

![已完成的本地后台任务](/img/open-science/v0.27.0/13-background-task-completed.png)

### 保持应用必需 Skills 可用

**Customize**、**Environment & Packages**、**Remote Compute (SSH)** 和 **Compute Environment Setup** 保持启用。开关为选中且禁用状态，并提供不可关闭的原因提示。内部支持 Skill 也保持可用，但不作为公开目录中的额外研究方法。

此规则不会安装科学软件依赖，也不会授予 Specialist 访问权限。见[必需 Skills](../skills/overview.md#为什么有些开关不能关闭)及[创建 Skill](../skills/create.md)中的 Save as skill 流程。

### 通过脚本管理集成

CLI 和 Task SDK 增加 Connector 列表、详情及启用/禁用操作，并提供自定义 Connector 管理能力。无可用系统凭据库的无界面 Linux 环境可在启动时显式选择文件凭据存储；默认仍使用系统存储。文件存储不加密，需要通过文件系统权限保护。

详见 [Connector CLI](../reference/cli.md#管理-connector-与凭据)、[SDK 方法](../reference/api.md#connector-管理方法)和 [Linux 凭据存储](../reference/server.md#linux-无界面服务的凭据存储)。

## 兼容性与已知问题范围
