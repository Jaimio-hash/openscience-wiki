# 更新日志 · v0.30.0

发布于 2026 年 9 月 15 日。本次更新增加了整理阅读记录和并行讨论的工具，并改善设置查找和 PDF 提取结果的使用方式。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.30.0) · [与 v0.29.0 的完整差异](https://github.com/aipoch/open-science/compare/v0.29.0...v0.30.0)

## 新增与更新的使用流程

| 功能 | 如何使用 |
| --- | --- |
| 私人书签 | 选择对话或预览文字，或框选 PDF 区域，选择 **For me**，保存书签并按需添加备注。从会话的 **Bookmarks** 返回原处；这些备注不会进入 Agent 上下文。[阅读书签](../guides/bookmarks.md) |
| 独立 Side Chat 标签页 | 在 Main 旁保留多个讨论，把批注移入指定草稿后再发送。确认 **Close Side chat** 会停止该旁聊并永久删除其保存的对话。[Side Chat](../guides/delegation.md) |
| 设置中心 | 按 **Intelligence、Connections、Workspace、System** 查找面板，或使用顶部搜索定位设置。[设置中心总览](../settings/overview.md) |
| 全局搜索 | 点击类别旁的 **Advanced filters**，调整范围、排序、时间和对应结果类型的筛选。收起筛选栏后，已选条件仍然生效。[导航与搜索](../guides/navigation.md) |
| PDF 提取证据 | 链接 PDF，并在 **Figures and tables** 完成分析后，Agent 可以列出和读取已缓存的图、表及算法内容。[PDF 证据](../guides/previews.md#pdf-agent-evidence) |
| 模型提供商目录 | SenseNova 提供 **China** 和 **Global** 区域；框架与账号支持时，可选择目录中的免费网关模型。[模型接入](../guides/providers.md#provider-regions) |

## 改进与修复

- 会话悬停详情增加会话编号；Skill、Connector 和 Specialist 的批量操作使用一致的操作区。
- 改善 PDF 原生图表布局恢复，并修复旋转页面的文字选区。提取结果仍需对照原文检查。
- 数据接口修复涵盖 dbSNP 删除等位基因保留、VEP 等位基因处理与唯一转录本计数，以及 BioMart 布尔筛选的排除条件。
- 减少空闲时的后台工作，改善更新进度显示、运行环境恢复提示、Windows 终端操作、结果交付和应用退出的稳定性。

## 使用前需要了解

书签属于单个会话，不随 `.science` 研究包导出，也不跨机器同步。导入的研究包仍为只读；可复现性检查仍针对选定的保存版本，不会重放整个会话。对应流程见[研究包](../guides/research-packages.md)和[可复现性](../guides/reproducibility.md)。

更新应用请参阅[安装与更新](../guides/installation.md)。此前变化见 [v0.29.0](./v0.29.0.md)。

后续变化见 [v0.30.1](./v0.30.1.md)。
