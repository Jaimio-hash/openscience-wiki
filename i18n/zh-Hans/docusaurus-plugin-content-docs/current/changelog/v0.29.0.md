# 更新日志 · v0.29.0

发布于 2026 年 9 月 13 日。本次更新增加了 Skill 发现、研究记录传递和本地 PDF 图表提取能力，并更新了 Codex Side Chat 与外部 R 包安装支持。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [与 v0.28.0 的完整差异](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## 新增功能

### 从市场发现与安装 Skills

在 **Marketplace** 浏览分类、作者和可用的评估详情，然后从卡片安装 Skill。更新版本需要显式确认。批量管理支持按筛选结果选择、顺序安装、完成当前项后停止，以及重试失败项。

目录和软件包会依据带签名的分发记录进行校验。这能确认分发身份，但不能代替判断方法是否适用，也不会替你准备科研依赖。见[市场功能说明](../skills/marketplace.md)。

### 用 .science 包传递研究记录

可以将空闲会话导出为 **.science** 包。默认使用 **Essential** 导出范围；**Full** 和其他选项可以包含更多文件、版本与复现输出。通过 Project 菜单导入、将包拖入项目，或打开关联文件后，先检查预览，再确认目标项目。

导入的会话保留研究历史与证据，供查看和引用。它是只读记录，不能执行或继续对话。随包收到的验证记录仍属于来源端的验证声明，不表示接收电脑已重新检查。见[研究包说明](../guides/research-packages.md)。

### 在本地提取 PDF 图表

可选的 **Figures and tables** 流程会安装经过校验的模型资源，并在本地分析 PDF。之后可以重新打开缓存结果、复制或下载图片，以及将表格导出为 HTML、TSV 或 Markdown。

使用前应对照原文页检查提取内容，尤其是合并表头、脚注和跨页内容。未解析的文字与待核对提示会保留，提取出的表格仍需核对后再用于分析。见 [PDF 提取说明](../guides/previews.md#pdf-extraction)。

### 在外部 R 环境中安装包

外部 R 环境现在可以获得针对已有、可写的个人 R 库的安装授权。选择合适的库后启用 **Allow package install**；系统库和站点库不在授权范围内，已有授权也可以撤销。

具备所需依赖锁文件时，外部 R 和 Python 环境还可提供有条件的包恢复证据。恢复需要满足匹配条件，并由用户运行恢复脚本。恢复软件包本身不代表研究结果已复现。见 [R 安装与恢复条件](../guides/runtimes.md#external-r-packages)。

## 改进与修复

| 范围 | 变化 |
| --- | --- |
| Codex Side Chat | 移除了全局提供方使用 Codex 订阅时禁用桌面入口的旧判断。会话状态和恢复条件仍可能导致入口不可用。见[修复说明](https://github.com/aipoch/open-science/pull/2460) |
| Connectors | 设置支持批量启用/禁用。Literature Graph 增加 Crossref 文献及更新查询、DataCite 条目及搜索方法；Rfam 序列搜索改用修复后的批量端点。见[管理更新](https://github.com/aipoch/open-science/pull/2507)、[数据查询更新](https://github.com/aipoch/open-science/pull/2509) |
| CLI 与 SDK | 增加运行时列表及安装、终端配置初始化和 Codex 首次设置能力，继续使用依托应用运行的 CLI。见[运行时](https://github.com/aipoch/open-science/pull/2489)、[初始化](https://github.com/aipoch/open-science/pull/2474)、[Codex 设置](https://github.com/aipoch/open-science/pull/2487) |
| 任务文件下载 | 保留产物的版本身份，修复了已完成任务下载输出时返回 HTTP 500 的一类原因。见[下载修复](https://github.com/aipoch/open-science/pull/2490) |

其他变化改善了启动速度、更新重试、Windows 操作恢复、文献元数据及科研 Skill 处理。完整列表见[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.29.0)。

安装步骤见[安装与更新](../guides/installation.md)，更早的变化见 [v0.28.0](./v0.28.0.md)。

后续变化见 [v0.30.0](./v0.30.0.md)。
