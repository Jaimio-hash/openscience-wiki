# 更新日志 · v0.28.0

发布于 2026 年 9 月 11 日。本次更新支持根据已保存结果的执行记录重新运行并比较输出，同时扩展全局搜索，并要求用户主动加载回复中的远程媒体。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [与 v0.27.0 的完整差异](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## 新增功能

### 检查已保存的结果能否复现

**Reproducibility** 根据某个文件版本记录的输入、执行过程和环境信息，在隔离环境中重新运行。开始前先检查所需证据，完成后逐项查看输出比较结果。可以检查单个版本，也可以批量检查多个版本，并导出检查记录。

运行完成不等于输出一致。证据缺失或操作不受支持时，检查可能无法继续。这项功能针对已捕获的文件版本，不会重放整个会话。发起检查需要桌面界面，大型 RDS/H5AD 文件不会被载入进行内容比较。见[功能说明](../guides/reproducibility.md)。

### 一起搜索消息、文件与文献

全局搜索现在覆盖项目、会话、消息正文、上传与生成的文件，以及文献库条目和集合。可以按类别及相关字段筛选，选择结果查看上下文，再打开对应消息或文件。支持搜索适用文本文件的内容，但不表示所有二进制格式都能全文检索。

分组结果可以在各类别内继续加载。切换结果时，详情面板可以保持打开。见[搜索更新](../guides/navigation.md)。

### 更新应用管理的 Codex 运行时

Agent 设置分别显示原生 Codex CLI 和 ACP 适配器的版本。较旧的应用管理安装可以显式更新到经过测试的组合；外部安装的 CLI 仍需自行维护。替换前应完成或停止正在使用该运行时的任务。这与更新 Open-Science 应用本身是两项操作。见[运行时更新说明](../guides/frameworks.md#update-codex)。

### 在 Windows 试用 WSL2 Bash

Windows x64 新增可选的 **WSL2 Bash Preview**，默认仍使用 PowerShell。使用预览功能需要主动启用、版本匹配的资源及通过就绪检查；日常使用 Windows 版不要求先配置它。见[预览功能范围](../guides/runtimes.md#wsl2-preview)。

## 影响现有配置的变化

| 范围 | 使用时的变化 |
| --- | --- |
| 远程模型连接 | 远程端点必须使用 HTTPS。已有远程 HTTP 配置仍可编辑，但更正前不能运行。localhost 与回环地址仍支持 HTTP |
| 回复中的媒体 | 远程图片、音频和视频等待主动加载。加载前查看目标主机，授权只针对当前显示的媒体元素 |
| 发送给模型的图片 | 模型输入副本会移除附加元数据，原始文件保留 |

查看或复用旧消息时也会应用这些规则。见[连接与媒体变化](https://github.com/aipoch/open-science/pull/2420)。

已配置的 Conda、PyPI 和 CRAN 镜像主机会在本次包管理操作中获得临时授权。这不会增加永久 Notebook 权限，也不会自动授权跳转后的其他主机；镜像不可用或 DNS 返回无效地址的问题仍需分别处理。见[包镜像更新](../guides/network.md)。

## 改进与修复

更新流程改进了安装包校验和重试处理。其他修复涉及 Windows R 启动、PubMed 元数据、会话保存和故障恢复。完整列表见[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.28.0)。

安装步骤见[安装与更新](../guides/installation.md)。继续阅读 [v0.29.0](./v0.29.0.md)，或回看 [v0.27.0](./v0.27.0.md)。
