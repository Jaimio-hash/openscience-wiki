# Changelog - v0.30.0 {/* #changelog--v0300 */}

Выпущен сентябрьский 15, 2026. Это обновление добавляет инструменты для организации чтения и параллельных обсуждений, а также облегчает доступ к настройкам и извлеченным доказательствам PDF.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.30.0) · [Изменения после v0.29.0](https://github.com/aipoch/open-science/compare/v0.29.0...v0.30.0)

## Новые и обновленные рабочие процессы {/* #new-and-updated-workflows */}

| Особенность | Как использовать |
| --- | --- |
| Частные закладки | Выберите диалог или предварительный просмотр текста, или регион PDF, выберите **For me**, и сохранить закладку с дополнительной запиской. Возвращение через **Bookmarks** на сессии. Эти заметки не входят в контекст агента. [Чтение закладок](../guides/bookmarks.md) |
| Независимые вкладки Side Chat | Держите несколько обсуждений открытыми рядом с Main. Переместите аннотации в предполагаемый проект перед отправкой. подтверждающий **Close Side chat** Прекратите этот чат и навсегда удалите сохраненный разговор. [Side Chat](../guides/delegation.md) |
| Центр расположения | Найти панели под **Intelligence**, **Connections**, **Workspace** и **System**или использовать поиск заголовка для перехода на панель. [Обзор настроек](../settings/overview.md) |
| Глобальный поиск | Открыть **Advanced filters** Помимо категорий, для корректировки объема, порядка, времени и конкретных результатов фильтров. Коллапс этой колонки сохраняет применяемые фильтры. [Навигация и поиск](../guides/navigation.md) |
| Извлеченные доказательства PDF | Свяжите PDF и проанализируйте его **Figures and tables**. Затем агент может перечислить и прочитать кэшированные фигуры, таблицы и алгоритмы. [Доказательства PDF](../guides/previews.md#pdf-agent-evidence) |
| Каталог поставщиков | SenseNova предлагает **Китай** и **Global** регионов. Бесплатные шлюзовые записи доступны там, где их поддерживают фреймворк и учетная запись. [Настройка поставщика](../guides/providers.md#provider-regions) |

## Улучшения и исправления {/* #improvements-and-fixes */}

- Детали зависания сеанса включают номер сеанса; Skill, Connector и Specialist пакетные элементы управления используют последовательную область действия.
- Решения PDF улучшают восстановление нативной фигуры / таблицы и выбор текста на вращающихся страницах. Добыча все еще нуждается в проверке на источник.
- Connector фиксирует сохранение аллелей удаления dbSNP, правильную обработку аллелей VEP и количество уникальных транскриптов, а также ремонт исключенных булевых фильтров BioMart.
- Незанятая фоновая работа сокращается. Прогресс обновления, сообщения о восстановлении времени выполнения, обработка оболочки Windows, доставка результатов и отключение приложений получают исправления надежности.

## Перед использованием новых рабочих процессов {/* #before-using-the-new-workflows */}

Закладки остаются в рамках одной сессии и исключаются из экспорта `.science` и кросс-машинной синхронизации. Импортные исследовательские пакеты остаются только для чтения. Воспроизводимость по-прежнему проверяет выбранную сохраненную версию; Он не повторяет весь сеанс. См. [исследовательские пакеты](../guides/research-packages.md) и [воспроизводимость](../guides/reproducibility.md) для соответствующего рабочего процесса.

Используйте [Установка и обновление](../guides/installation.md) для обновления приложения. Ранее изменения коснулись [v0.29.0](./v0.29.0.md).

Продолжить [v0.30.1](./v0.30.1.md) для следующего выпуска.
