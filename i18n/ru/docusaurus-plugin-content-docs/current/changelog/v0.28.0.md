# Changelog - v0.28.0 {/* #changelog--v0280 */}

Выпущен сентябрьский 11, 2026. Эта версия добавляет проверки, которые повторяют записанную процедуру сохраненного результата и сравнивают выход. Он также расширяет глобальный поиск и делает загрузку удаленных носителей явной.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [Изменения после v0.27.0](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## Новые особенности {/* #new-features */}

### Проверьте, воспроизводится ли сохраненный результат {/* #check-whether-a-saved-result-reproduces */}

**Reproducibility** использует входные данные захваченной версии файла, запись выполнения и информацию об окружающей среде для повторного запуска своей процедуры в изоляции. Проверяйте необходимые доказательства перед началом проверки, а затем проверяйте результат сравнения каждого вывода. Проверки могут охватывать одну версию или партию версий, и их записи могут быть экспортированы.

Один только завершенный пробег не означает, что результаты совпадают. Недостающие доказательства или неподдерживаемые операции могут предотвратить проверку. Эта функция проверяет захваченные версии; Он не повторяет весь сеанс. Для запуска проверки требуется интерфейс рабочего стола, а большие файлы RDS / H5AD не загружаются для сравнения контента. [Особенности](../guides/reproducibility.md).

### Поисковые сообщения, файлы и литература вместе {/* #search-messages-files-and-literature-together */}

Глобальный поиск теперь включает в себя проекты, сессии, текст сообщения, загруженные и сгенерированные файлы, а также библиотечные записи и коллекции. Отфильтровать по категориям и соответствующим полям, выбрать результат для проверки его контекста, затем открыть соответствующее сообщение или файл. Поддерживаемый контент текстовых файлов доступен для поиска; Это не подразумевает полнотекстовую индексацию каждого двоичного формата.

Сгруппированные результаты загружают дополнительные матчи в каждой категории. Панель деталей может оставаться открытой, пока вы перемещаетесь между результатами. [Поисковые изменения](../guides/navigation.md).

### Обновление приложения Codex Runtime {/* #update-an-app-managed-codex-runtime */}

Настройки агентов отличают нативную версию Codex CLI от версии адаптера ACP. Более старая установка, управляемая приложением, может получать явное обновление тестируемой пары. Внешне установленные CLI по-прежнему требуют ручного обслуживания. Завершить или прекратить выполнение задач с использованием времени выполнения перед его заменой; Отдельно стоит отметить обновление Open-Science. [Обновления Runtime](../guides/frameworks.md#update-codex).

### Попробуйте WSL2 Bash на Windows {/* #try-wsl2-bash-on-windows */}

Windows x64 получает дополнительный **WSL2 Bash Предварительный просмотр**. PowerShell остается по умолчанию. Использование предварительного просмотра требует явной активации, согласования активов и успешной проверки готовности; Это не обязательное условие для обычного использования Windows. [Предварительный обзор](../guides/runtimes.md#wsl2-preview).

## Изменения, которые влияют на существующие системы {/* #changes-that-affect-existing-setups */}

| Область | Чего ожидать |
| --- | --- |
| Дистанционные модельные соединения | Для удаленных конечных точек требуется HTTPS. Существующие удаленные конфигурации HTTP остаются редактируемыми, но не могут работать до исправления. HTTP поддерживается для адресов локального хоста и обратной связи. |
| СМИ в ответах | Удаленные изображения, аудио и видео ждут активации. Проверять хосты назначения перед погрузкой; Разрешение распространяется на этот отображаемый элемент. |
| Изображения, отправленные на модель | Модели-входные копии удаляют вспомогательные метаданные; Оригинальные файлы сохранены. |

Эти изменения также применяются при просмотре или повторном использовании старых сообщений. [Связь и медиа-изменения](https://github.com/aipoch/open-science/pull/2420).

Настроенные хосты Conda, PyPI и CRAN временно разрешены для работы с пакетами. Это не добавляет постоянных разрешений Notebook или автоматически разрешает перенаправления на другие хосты. Он также не разрешает недоступное зеркало или недействительный ответ DNS. [Зеркальные изменения пакета](../guides/network.md).

## Улучшения и исправления {/* #improvements-and-fixes */}

Обновления улучшают верификацию установщика и поведение повторного использования. Другие исправления включают запуск Windows R, метаданные PubMed, сохранение сеанса и восстановление после сбоя. Проверьте [официальное освобождение](https://github.com/aipoch/open-science/releases/tag/v0.28.0) для полного списка.

Для установки см. [Установка и обновление](../guides/installation.md). Продолжить [v0.29.0](./v0.29.0.md) или просмотреть [v0.27.0](./v0.27.0.md).
