# Changelog - v0.27.0 {/* #changelog--v0270 */}

Этот релиз расширяет импорт литературы, добавляет выполнение фона и улучшает восстановление во время исследовательских сессий. Кроме того, поддерживается поддержка Skills, необходимого для приложений, и добавляется управление Connector для пользователей CLI и SDK.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.27.0) · [Изменения после v0.26.0](https://github.com/aipoch/open-science/compare/v0.26.0...v0.27.0)

## Новые особенности {/* #new-features */}

### Импорт нескольких PDF-файлов вместе {/* #import-several-pdfs-together */}

Выбор нескольких PDF-файлов открывает один диалог импорта с выбором файлов, резюме назначения, политикой соответствия идентификаторам, прогрессом и результатами каждого файла. **Stop** завершает дальнейшую обработку; **Retry unfinished** возобновляет незавершенный отбор. Выбирая один PDF, вы сохраняете маршрут редактирования метаданных.

Выберите, следует ли повторно использовать соответствующую ссылку, вести отдельную запись или заполнять пустые поля. Библиотека также показывает свою активную совокупность независимо от поисковых фильтров и может обогащать метаданные из обнаруженного DOI. Проверьте извлеченный заголовок и идентификаторы: завершенный импорт не гарантирует правильных метаданных. Смотрите [Библиотека литературы и цитаты](../guides/library.md).

![Загрузка пакета PDF с двумя документами PRISMA](/img/open-science/v0.27.0/02-pdf-batch-ready.png)

### Продолжайте работать, пока выполняются задачи {/* #continue-working-while-tasks-run */}

Поддерживаемые Python, R, стойкая REPL и оболочка работы могут работать в фоновом режиме. Сеанс отслеживает личность задачи, статус, истекшее время и отмену; **Open** возвращается к соответствующему ходу. Результаты могут быть автоматически доставлены в разговор для локальных запусков и удаленных вычислительных работ.

Проверяйте сохраненные файлы после завершения. Дистанционные рабочие места по-прежнему требуют настроенного хоста и подходящих ресурсов. Смотрите [Фоновые задачи](../guides/notebook.md#background-tasks-and-result-delivery).

![Завершена локальная фоновая задача](/img/open-science/v0.27.0/13-background-task-completed.png)

### Держите приложение Skills доступным {/* #keep-application-skills-available */}

**Customize**, **Окружающая среда и пакеты**, **Дистанционные вычисления (SSH)** и **Настройка вычислительной среды** теперь остаются включенными. Их проверенные выключатели объясняют, почему их нельзя отключить. Внутренняя поддержка Skills также остается доступной. Они не являются дополнительными публичными методами в каталоге.

Это не устанавливает научные зависимости или не предоставляет доступ к Specialist. См. [Требуется Skills](../skills/overview.md#why-some-switches-cannot-be-turned-off) и [Создайте Skill](../skills/create.md) для сбережений как процесс работы с навыками.

### Управление интеграцией из сценариев {/* #manage-integrations-from-scripts */}

CLI и Task SDK добавляют обнаружение Connector, инспекцию и включение / отключение элементов управления, наряду с пользовательским управлением Connector. Безголовый Linux также получает явную опцию хранения учетных данных на основе файлов, когда хранилище учетных данных ОС недоступно; Хранение ОС остается по умолчанию. Файловый магазин незашифрован и должен быть защищен с помощью средств управления доступом к файловой системе.

[Команды Connector CLI](../reference/cli.md#manage-connectors-and-credentials), [Методы SDK](../reference/api.md#connector-management-methods) и [Хранение учетных данных Linux](../reference/server.md#credential-storage-on-headless-linux).

## Совместимость и известные проблемы {/* #compatibility-and-known-issues */}

Релиз включает в себя [#2394](https://github.com/aipoch/open-science/pull/2394), который исправляет Codex-подписку Side Chat и возобновляет работу в бэкэнде. Тот же помеченный десктопный код сохраняет защиту провайдера, которая отключает его ввод меню; Новая проверка этого исходного рабочего стола все еще доходила до этого охранника. Отслеживайте это как несоответствие интерфейса / бэкэнда, требующее расследования и сквозной проверки, а не преднамеренное отсутствие поддержки. Смотрите [Доступность Side Chat](../guides/delegation.md).

Этот десктопный охранник входа был удален в [v0.29.0](./v0.29.0.md); Описываемое выше ограничение относится к источнику v0.27.0.

Для установки или обновления см. [Установка и обновление](../guides/installation.md). Ранее изменения коснулись [v0.26.0](./v0.26.0.md).
