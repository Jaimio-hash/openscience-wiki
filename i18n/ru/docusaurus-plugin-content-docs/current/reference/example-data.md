# Примерные данные и ожидаемые результаты {/* #example-data-and-expected-results */}

Используйте эти общедоступные файлы для воспроизведения примеров документации. Описание источника, контрольная сумма оригинального файла и базовый уровень выборки-QC находятся здесь; Индивидуальные руководства по функциям ссылаются на них вместо повторения истории набора данных.

## Исходный и входной контракты {/* #source-and-input-contract */}

[Серия рекордов GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE60450) поставляет оригинальный `GSE60450_Lactation-GenewiseCounts.txt.gz`. [Результаты анализа рабочего процесса RNA-seq](https://pmc.ncbi.nlm.nih.gov/articles/PMC4934518/) предоставляет методологический контекст для этого набора данных. Наш пример останавливается на описательном преданализе QC. Он не воспроизводит полный анализ этой статьи.

| Недвижимость | Проверенная стоимость |
| --- | --- |
| Декомпрессированный файл | GSE60450_Lactation-GenewiseCounts.txt |
| Размер | 1,340,161 байты |
| Генные ряды | 27,179 |
| колонны | EntrezGeneID, Length и 12 столбцы выборочного счета |
| SHA-256 | `128d2411f3169de0cac9963c30152bb5c9a3083ac80fd25651b97cf4b7304691` |
| Дублирующие идентификаторы генов / недостающие записи / недействительные подсчеты | 0 / 0 / 0 |

<a href="/docs/examples/gse60450/GSE60450_Lactation-GenewiseCounts.txt" download>Скачать неизмененный декомпрессированный вход</a> или <a href="/docs/examples/gse60450/GSE60450_Lactation-GenewiseCounts.txt.gz" download>Оригинальный сжатый файл</a>. Инструмент метаданных Omics Archives приложения может возвращать дополнительные URL-адреса; Он не загружает таблицы подсчета автоматически. Этот источник был загружен отдельно и загружен через файлы Attach.
