# Форматы файлов и ограничения {/* #file-formats-and-limits */}

Посмотрите маршрутизацию файлов и ограничения здесь. Загрузка файла, предварительный просмотр его, разбор его в инструменте и отправка его в модель являются отдельными возможностями. Принятая загрузка не является обещанием встроенного зрителя или понимания модели.

## Предварительная маршрутизация {/* #preview-routing */}

| Содержимое | Признанные расширения | Поведение и границы |
| --- | --- | --- |
| Изображение растера/вектора | `avif`, `gif`, `jpeg`, `jpg`, `png`, `svg`, `webp` | предварительный просмотр изображения; Ввод модели по-прежнему зависит от поддержки изображения |
| ТИФФ | `tif`, `tiff` | Выделенный декодер с ограничениями файлов, пикселей и памяти |
| Ограниченный стол | `csv`, `tsv` | Первый ряд рассматривается как заголовки; Ограниченные ряды/колонки |
| последовательность | `fa`, `faa`, `fasta`, `ffn`, `fna`, `frn` | инспекция FASTA; просмотр не подтверждает метод анализа |
| Структура | `pdb` | Структурный зритель; не является качественной оценкой прогноза |
| Молекула/реакция | `mol`, `sdf`, `smi`, `smiles`, `rxn` | Выделенный молекулярный превью; не предполагать `mol2` имеет одинаковую маршрутизацию |
| PDF | `pdf` | Выделенный считыватель документов с контролем страницы |
| Слово | `docx` | офисный рендерер; наследие `doc` не перенаправляется на DOCX парсинг |
| Электронная таблица | `xls`, `xlsx` | Предварительный просмотр офисных электронных таблиц; Выполнение модели – это отдельная операция. |
| Презентация | `pptx` | канцелярский презентационный рендеринг; наследие `ppt` не направляется на PPTX парсинг |
| Markdown | `md`, `markdown` | Отредактированный документ с поддерживаемыми действиями текстовой версии |
| HTML | `htm`, `html` | Изолированный превью HTML; не получают привилегий по заявкам |
| JSON | `json` | Структурированный предварительный просмотр, включая признанный план JSON |
| Код | `bash`, `bib`, `bibtex`, `css`, `js`, `jsx`, `py`, `r`, `sh`, `tex`, `ts`, `tsx` | выделенный источник; Открытие сценария не выполняет его |
| Простой текст | `conf`, `config`, `ini`, `iqtree`, `log`, `nwk`, `state`, `toml`, `tree`, `treefile`, `txt`, `xml`, `yaml`, `yml` | Ограниченный текстовый предварительный просмотр |
| Другие файлы | Непризнанное расширение/содержание | Fallback/download, если таковые имеются; `.ipynb` Экспорт не подразумевает выделенного редактора предварительного просмотра файлов |

Маршрутизатор также имеет узкий резервный MIME для подходящих файлов без расширения. Вводящие в заблуждение метаданные Office MIME не делают устаревший формат совместимым с рендером OOXML.

[Точная таблица маршрутизации](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/preview-support.ts), [реестр рендеринга](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/previews/preview-registry.tsx).

## Размер и пределы отображения {/* #size-and-display-limits */}

Приведенные ниже единицы являются двоичными единицами: 1 MiB = 1,048,576 байт; 1 GiB = 1,073,741,824 байт. Интерфейс может маркировать эти значения MB или GB.

| граница | Предельный источник | Какое ограничение применяется к |
| --- | ---: | --- |
| Один проект скачать | 10 GiB | Загрузить вход, а не предварительный просмотр или модель контекстного бюджета |
| Oneload chunk скачать | 8 MiB | размер пересадки; не ограничивает доступ к файлу пользователя |
| Композиторские вложения | 10 | Подсчет прикреплений за сообщение |
| Композиторский артефакт упоминает | 10 | Явные ссылки на артефакты в сообщении |
| По умолчанию text-preview read | 1 MiB | Первоначальный ограниченный контент читать |
| Максимально запрашиваемый общий предварительный просмотр читать | 10 MiB | Общий читательский потолок; У специализированных читателей есть свои ограничения. |
| CSV/TSV видимые данные | 100 строки × 24 столбцы | Отображаемые данные после первой/заголовковой строки; не размер исходного набора данных |
| Предварительный просмотр Office File Preview | 40 MiB | Предварительный просмотр Office Preview |
| Превью файла TIFF | 40 MiB | Выделенный лимит файлов TIFF |
| TIFF расшифровывает пиксели | 25,000,000 | Предварительный просмотр декодирования бюджета пикселей |
| TIFF расшифровывает распределение | 256 MiB | Предварительный просмотр бюджета памяти декодера |
| Количество страниц TIFF | 512 | Префейс-кап; Другие структурные ограничения также применяются |
| Автоматическое извлечение/приобретение PDF | 50 MiB | Автоматический текст PDF / путь приобретения; Не относитесь к нему как к общему пределу загрузки проекта |

Применяйте перечисленные ограничения к соответствующей операции: лимиты предварительного просмотра, лимиты загрузки и бюджеты пакетов являются отдельными. Для негабаритного файла используйте исходный файл с совместимым внешним считывателем или разделите ввод в соответствии с методом.

Таблица, в которой говорится, что **Показаны строки 100** может содержать больше строк источника. Используйте фактический анализ файлов в Notebook, чтобы установить его размер. В случае GSE60450 источник имеет строки генов 27,179, а образец QC CSV имеет двенадцать строк: два файла суммируют разные единицы.

## Импорт литературы и выпуск цитирования {/* #literature-import-and-citation-output */}

| Пункт | контракт | Различие |
| --- | --- | --- |
| Импорт справочной документации | BibTeX, RIS, NBIB | импорт библиографических записей; не гарантирует приложенный полный текст |
| Импорт контента | До 32 MiB с записью 1,000 | Разделите большие коллекции на рецензируемые партии |
| Импорт в стиле цитирования | CSL, вплоть до 1 MiB | Определение стиля, а не литературная коллекция |
| Экспорт библиографических записей | BibTeX или RIS | Не думайте, что импорт NBIB означает экспорт NBIB. |
| Локальное форматирование цитирования | `en-US`, `zh-CN` | Язык цитирования отделен от языка UI приложения |
| Название коллекции | 200 персонажи | Ярлык коллекции |
| Описание коллекции | 1,000 персонажи | Описывает коллекцию; Не заменяет контекст агента проекта |

Результат метаданных DOI не является загруженным PDF. Приложенный PDF не является доказательством того, что агент прочитал его полный текст. Проверьте как вложение, так и фактическую запись исполнения / доказательства.

[Литературные схемы и ограничения](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/literature.ts), [Форматирование импорта/экспорта](https://github.com/aipoch/open-science/blob/v0.26.0/src/main/literature/citation-formatter.ts).

## Версия и идентификатор загрузки {/* #version-and-download-identity */}

| Идентификатор | Использовать | Не заменяйте |
| --- | --- | --- |
| Имя отображения | Найти файл в интерфейсе | Само по себе имя не идентифицирует неизменный контент. |
| Файл/идентификатор артефакта | Определите управляемый объект | Скачанный путь — это не тождество объекта |
| Версия ID / Version ID `vN` | Осмотрите точную сохраненную версию и ее происхождение | Последний контент может отличаться от версии, используемой для результата. |
| Контрольная сумма | Сравнение байтов между исходными и сохраненными копиями | Имена совпадений не устанавливают совпадающие контрольные суммы |
| Скачать destination | Найти внешнюю копию | Редактирование этой копии автоматически не обновляет управляемую версию. |

Для выполнения операций используйте [Notebook и доказательства](../guides/notebook.md) и [рабочий процесс с публичными данными](../workflows/data-quality.md). Эта ссылка централизует границы, чтобы эти руководства могли сосредоточиться на задаче.

Для элементов управления, специфичных для формата, см. [предварительный просмотр](../guides/previews.md#diagram-source-and-format-specific-controls): Переключение источника / рендеринга русалки, одностраничное условие чтения PDF, ограниченные таблицы, выбор рабочих листов и обработка страниц TIFF. Поддержка предварительного просмотра не обеспечивает успешного ввода или экспорта модели.
