# Делегировать и проверять работу {/* #delegate-and-verify-work */}

Делегирование дает отдельное задание ребенку на роль, в то время как агент Main координирует разговор. Выбор Specialist для выступления в основном разговоре и делегирование задачи ребенку - это разные действия.

## Подготовьте ограниченную передачу {/* #prepare-a-bounded-handoff */}

| Требуемая информация | Пример |
| --- | --- |
| Роль | RNA-seq QC Рецензент, сохраненный ID `rna-seq-qc-reviewer` |
| Ввод | Заполните GSE60450-образец-QC CSV, или действительную текущую неизменяемую версию файла |
| Задача | Проверить 12 не упущенные уникальные полные идентификаторы выборки и идентификатор гена на выборку |
| доставляемый | Одна контрольная таблица плюс арифметический результат каждого образца |
| Границы | только для чтения; никаких новых пакетов; Никакой дифференциальной интерпретации выражения |

1. Создайте / настройте [роль](./identity.md) и подтвердите, что он включен.
2. В разговоре **Agent controls** включите **Delegation**. Подтвердите предполагаемую модель и рабочую аутентификацию.
3. Попросите агента Main четко делегировать, определить роль и предоставить полную задачу. Если вы используете передачу файлов, позвольте приложению разрешить текущие версии; Не изобретайте идентификаторы и не передавайте имена файлов в качестве ссылок на версию.
4. Следите за фактической деятельностью делегации и статусом ребенка. Прогрессивный приговор от агента Main не является детской записью.
5. Откройте детский чип / предварительный просмотр **Subagents**. Выберите задачу в **Subagent Frame** и прочитайте ее транскрипт, результаты инструмента и состояние терминала.
6. Отвечайте на любой запрос разрешения ребенка в родительском разговоре после проверки его объема. Затем сравните возвращенный результат с запрошенными проверками приемки.

## Проверить отдачу и возвращенный результат {/* #check-the-handoff-and-returned-result */}

### Проверьте маленький встроенный стол {/* #verified-example-twelve-sample-invariants */}

<p className="example-label"><strong>Практический пример</strong> Делегировать проверку таблицы из двенадцати образцов</p>

Скачайте полный <ExampleDownload path="/examples/gse60450/rnaseq-sample-qc.csv">образец QC CSV</ExampleDownload> и вставьте его заголовок и все двенадцать строк непосредственно под запросом. Сохраняйте все столбцы и полные идентификаторы образцов. В примере используется активированная роль, созданная в [Идентификатор Specialist](identity.md); Python должен быть включен для его арифметики. Для этой ограниченной проверки не требуется дополнительный Skill.

> Об этом сообщает RNA-seq QC Reviewer. Используйте только полный встроенный CSV ниже. Выполните арифметику в Python, проверьте двенадцать различных полных идентификаторов выборки и проверьте zero_count_genes + detected_genes_count_gt_0 = 27179 для каждой строки. Верните каждый результат и укажите, что эти проверки предоставили сводные данные, а не независимый доступ к исходной графовой матрице.

![Завершенная подзадача Specialist с проверками на выборку](/img/open-science/capabilities-walkthrough/15-specialist-delegated-result.webp)

В этом примере ребенок запустил Python Notebook и вернул **12 строки, 12 различные не упущенные идентификаторы, и 12/12 суммы, равные 27,179**. Для первого полного идентификатора выборки `8,664 + 18,515 = 27,179`. Численные поля были полными и неотрицательными.

Это подтверждает последовательность представленного резюме. Он не может самостоятельно воспроизводить результаты/медики из исходной матрицы, проверять условия выборки или устанавливать биологические пороги качества.

### Выберите отдельную модель {/* #choose-a-separate-model */}

Установите детскую модель независимо от Main.



Выберите фиксированную модель под **Settings → Model → Subagent** перед делегированием. Откройте запись ребенка, чтобы проверить его фактическую модель. Основной ярлык модели разговора не идентифицирует ребенка. В реализованной конфигурации Main использовал `gpt-5.6-sol`, а в записи исполнения для детей использовался `gpt-5.6-luna`, как через аутентификацию подписки Codex.

### Передайте файл ребенку {/* #pass-a-file-to-the-child */}

<p className="example-label"><strong>Пример</strong> Передайте файл sample-QC в детское задание.</p>

1. Прикрепите исходный файл через меню вложения разговора и дождитесь завершения загрузки.
2. Попросите Main передать эту загруженную версию ребенку. Назовите необходимые проверки и выход; Не заменяйте имя файла или угадываемый идентификатор версии файла.
3. Откройте **Subagents** и выберите ребенка. В **Notebook** выберите этого ребенка в фильтре **Agent** и проверьте фактическое считывание файла.
4. Сравните количество строк ребенка, имена столбцов и контрольную сумму с источником. Откройте сохраненный выход и проверьте запрошенный расчет.

Для [Публичная выборка-метрика CSV](/examples/gse60450/portable-script/remote-rnaseq-qc-f1e10edbdf01-f1e10edbdf01.csv) ожидайте **Строки данных 12** и **269,027,617** как сумму `total_counts`. Контрольная сумма входа должна оставаться неизменной. Эти проверки касаются представленного резюме выборки; Они не пересчитывают исходную матрицу подсчета генов.

| Проверить | Необходимые доказательства |
| --- | --- |
| Версия принята | Приложение решило текущую неизменяемую версию загрузки / артефакта в своей собственной сессии. |
| Ребенок может читать | инструмент ребенка возвращает содержимое файла; Файлового имени или инсценированного пути недостаточно. |
| Проверки выполнены | Ребёнок провёл расчёт и его сэкономленный результат согласуется с источником. |

Если приложение сообщает о недоступном входе, повторно прикрепите файл и повторите его, используя его текущую версию. Если ребенок сообщает **`PermissionError: [Errno 1] Operation not permitted`**, сохраните точную ошибку и [сообщать](../guides/troubleshooting.md), если повторное прикрепление не восстановит прочитанное. Не перемещайте файлы во внутренние папки приложений, чтобы обойти ошибку.

### Сделайте Skill доступным для ребенка {/* #make-a-skill-available-to-the-child */}

Сначала импортируйте или создайте Skill. Для Specialist, назначьте его под ролью [Skills и коннекторы](capabilities.md); Затем начните новую делегированную задачу, которая явно называет метод. Попросите ребенка прочитать установленные инструкции перед их использованием.

Проверяйте активность инструмента ребенка на загруженную личность и контент Skill. Например, `rnaseq-count-qc` требует матрицы с необработанным генным счетом и описывает описательный QC; Двенадцатирядное резюме выборки не является взаимозаменяемым вводом. Успешное чтение пакета не означает, что анализ запущен. Проверяйте выполнение и сохраняйте результаты отдельно.

## Чтение сбоев точно {/* #read-failures-accurately */}

| Наблюдаемое или поддерживаемое государство | Значение и восстановление |
| --- | --- |
| Делегация уходит | Включите его для предполагаемого разговора перед повторным использованием. |
| Роль отключена/настройка неполная | Завершите настройку и включите предполагаемую сохраненную роль. |
| Ввод недоступен на этой сессии | Получите точную текущую версию артефакта или неизменяемую ссылку на версию загрузки. Путь, идентификатор артефакта и идентификатор версии - это разные значения. |
| Ожидание разрешения | Проверить операцию поименованного ребенка; Main Агент может ждать, а не вычислять. |
| Ребенок завершен | Прочитайте результаты и инструментальные доказательства; Завершение не является гарантией научной корректности. |
| Отмененный/неудавшийся | Сохранение частичного вывода и фактической ошибки. Не маркируйте замену агента Main как завершенную проверку Specialist. |

Маршрут, указанный в строке, подходит только для полной, ограниченной таблицы, объем доказательств которой указан; Это не является общей заменой файловой линии.
