# Обзор инструментов {/* #explore-tools */}

Выберите инструмент по нужному вам результату: извлеките запись, проверьте файл, выполните расчет или подключите внешний сервис. Приложение сочетает в себе эти возможности, но у них разные требования к установке и доказательствам.

## Доступность имеет несколько значений {/* #availability-has-several-meanings */}

**перечисленный** означает, что приложение знает ресурс. **Enabled** означает, что выбранный агент может использовать его. **Connected** подтверждает сеанс Connector, но не доказывает, что конкретный запрос действителен. **казнен** означает, что инструмент фактически возвращает результат или ошибку. **проверенный** означает, что результат был проинспектирован против задачи.

Локальные примеры включают в себя реальные числа GSE60450 RNA-seq, пользовательский сервер QC только для чтения, артефакт молекулы аспирина и открытые входы последовательности / структуры. Они используют скриншоты английского приложения в обоих языковых изданиях. Дистанционное выполнение GPU/SSH и учетные данные, недоступные на этом устройстве, остаются явно отличными от завершенных локальных операций.

## Предоставьте агенту ограниченный запрос {/* #give-the-agent-a-bounded-request */}

Укажите источник, работу и ожидаемый результат. Для запроса базы данных включите пространство имен идентификатора и небольшой предел результата. Для вычисления назовите ввод, выбранный язык и проверки. Запросить фактическую ошибку, если инструмент не может работать; Ответ, восстановленный из памяти модели, не является успешным вызовом инструмента.

[Навык](../skills/overview.md) предоставляет метод; a [Специалист](../specialists/overview.md) обеспечивает многоразовую роль. Ни один из них не устанавливает программное обеспечение автоматически, не предоставляет учетные данные и не делает недоступный файл доступным.
