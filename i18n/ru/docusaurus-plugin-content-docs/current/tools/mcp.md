# Коннекторы и MCP {/* #connectors-and-mcp */}

Connector предоставляет инструменты, которые может вызвать агент. Используйте эту страницу, чтобы выбрать тип интеграции и понять готовность. Для настройки полей, управления импортом / экспортом и подключением следуйте [Конфигурировать коннекторы](../guides/connectors.md).

## Выберите тип соединения {/* #choose-a-connection-type */}

| Тип | Используйте, когда | Требования |
| --- | --- | --- |
| Встроенный Connector | Приложение уже предоставляет необходимый источник данных или операцию. | включите его для предполагаемого агента; Некоторые услуги также требуют учетных данных |
| Местный сервер MCP | Инструмент должен работать на этом компьютере или читать локально доступные данные исследований. | Установленная пусковая установка, сервер и разрешенные пути ввода |
| Удаленный сервер MCP | Сервис раскрывает свои инструменты через размещенную конечную точку MCP | Конечная точка MCP поддерживает транспортировку HTTP/SSE и любую необходимую аутентификацию. |

**Molecule** обеспечивает рендеринг локальной структуры; Это не удаленная база данных. Выберите источник в [Научные базы данных](databases.md) или используйте [Научные зрители](viewers.md) для проверки молекулярных и последовательностей файлов. При выборе пусковой установки Docker не устанавливается движок контейнера или изображение сервера.

## Отличие подключения от доступности {/* #distinguish-connection-from-availability */}

Проверьте эти этапы по порядку. Прохождение одного не означает, что следующий удался.

| этап | Что проверить | Следующее действие |
| --- | --- | --- |
| Настройки | Правильная пусковая установка или конечная точка и необходимая аутентификация | Полный текст [Форма Connector](../guides/connectors.md) |
| Подключение | Сервер отвечает, и его инструменты обнаруживаются. | Проверьте результат соединения и фактические ошибки |
| Агентский доступ | Ресурс активирован для Main или назначен на предполагаемый Specialist. | Проверяйте связывание способностей агента |
| Операция | Выбранный инструмент принимает запрос и возвращает необходимые данные. | Используйте [Справочная информация об операции](../reference/connector-operations.md) для встроенных входов |
| Результаты исследований | Возвращенные идентификаторы, источник и область действия соответствуют задаче | Проверить ответ, прежде чем использовать его в качестве доказательства. |

Включенный коммутатор не является успешным вызовом службы. Ответ на метаданные не является загруженным полным текстом или графовой матрицей. Пользовательский ряд может открыть свой редактор конфигурации; Встроенные детали обеспечивают спецификацию инструмента.

## Диагностировать неудачную стадию {/* #diagnose-the-failing-stage */}

Для сбоев подключения определите, не сработала ли пусковая установка, транспортировка или аутентификация. Если соединение успешно, но вызов не удается, проверьте наличие агента и аргументы этого инструмента перед изменением конфигурации сервера. Сообщите о фактической возвращенной ошибке с помощью [устранение неполадок](../guides/troubleshooting.md).

Обнаружение MCP выполняется во время соединения. `host.mcp("server", "tools/list", {})` не является вызовом прикладного инструмента и может возвращать **Неизвестный инструмент**. Настраиваемый пример также показал внутренний отказ неизвестного образца как `connector_unavailable`; Этот ответ сам по себе не отличает недействительный образец от транспортного отказа.
