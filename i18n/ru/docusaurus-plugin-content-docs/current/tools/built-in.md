# Встроенные исследовательские инструменты {/* #built-in-research-tools */}

Встроенные операции соединяют разговор с файлами проекта, выполнением Notebook, записями литературы и сохраненными результатами. Они подвергаются воздействию через структуру активного агента; Интерфейс может группировать несколько операций по карте активности **Agent SDK** или **Notebook**.

## Операции по исследовательской задаче {/* #operations-by-research-task */}

| Семья | Снабжение | Операция и видимый результат | Проверьте, прежде чем полагаться на него |
| --- | --- | --- | --- |
| Обнаружение файлов и чтение | Проект/сессия и точный вклад | Перечисляет доступные файлы или читает поддерживаемый контент | Полное имя, источник и текущая версия; Каталог не является инспекцией файлового контента |
| Выполнение Notebook | Код Python/R, время выполнения и действительные ссылки на вход | Код ячейки, выход, время и состояние исполнения | Фактический язык / время выполнения, ошибки и проверки полных данных |
| Публикация артефакта | Поддерживаемый выходной путь или встроенный контент | Версия карты результата в разговоре/файлах | Откройте выход, сравните размеры/контент и сохраните его версию. |
| Поиск литературы / Импорт | Запрос, DOI/PMID или справочные файлы | Полученные записи, кандидаты в Inbox и записи в библиотеке | Идентификаторы источников, дубликаты, решение о пересмотре и полнотекстовый доступ |
| Планирование операций | Стадии исследований и критерии завершения | Сессионный план с поэтапными государствами | Статус соответствует фактически произведенным результатам |
| Память | Факт или инструкция, предназначенные для повторного использования | Сохраненная память в сконфигурированном объеме | Содержание и объем, отдельно от файлового хранилища проекта |
| Загрузка Skill | Доступный пакет ID | Методические инструкции и вспомогательные ресурсы | Предполагаемый пакет был прочитан; Загрузка не является вычислением |
| Делегация Specialist | Роль, задача и разрешенные входные данные | Детская активность и транскрипция субагентов | Ребенок действительно начал, провел необходимые проверки и сообщил об ограничениях. |
| Обзорная статья | Приемлемая конфигурация ответа и обзора | Рецензент проверяет, выводы и состояние коррекции | Какой ответ/версия были рассмотрены и какие доказательства имеются |

## Провести операцию до ее результата {/* #follow-an-operation-through-to-its-result */}

1. Отправьте запрос с вводом и желаемым выходом. Следуйте за [Первый проект](../guides/first-project.md) для небольшой задачи «от таблицы до отчета».
2. Расширьте карту активности и проверьте запрашиваемую операцию, объем ввода и разрешения.
3. После выполнения прочитайте результат инструмента. Решите ошибку, прежде чем полагаться на резюме.
4. Откройте сгенерированную файловую карту и проверьте ее содержимое. Для расчета откройте Notebook, чтобы проверить код производства и время выполнения.

[рабочий процесс качества данных](../workflows/data-quality.md) представляет собой полный научный пример. Контроль среды описан в [Notebook](../guides/notebook.md) и [Среды выполнения](../guides/runtimes.md).

## Читать Инструментальная активность {/* #read-tool-activity */}

| Элемент UI | Как использовать |
| --- | --- |
| Активная группа | Расширяет операции, сгруппированные в этом беге. |
| Инструмент / Агент SDK / Notebook | Открывает детали операции там, где это возможно. Прочитайте входные данные, ответ и ошибку, а не только групповую этикетку. |
| Код копирования / раскрытие кода | копирует или раскрывает представленный код; Он не выполняет второй прогон. |
| Разрешение / Разрешение / Отказ | Контролирует отображаемую операцию и выбранный объем. Проверьте, какой агент запрашивает его. |
| Сгенерированная файловая карта | Открывает фактический сэкономленный результат. |
| Открыть Notebook | Открывает записи выполнения сеанса и переменные. |
| Детский чип для задач | Открывается реально делегированное задание; Проверьте свою собственную стенограмму. |

## Избегайте общей путаницы ввода/вывода {/* #avoid-common-inputoutput-confusion */}

Загруженный файл, рабочий файл Notebook и версия артефакта связаны, но отличаются друг от друга. Файл, видимый в одном списке, еще не может быть установлен в ядре ребенка. Используйте текущую ссылку, предоставленную приложением; Не восстанавливайте недоступный вход, угадывая путь или заменяя идентификатор версии артефакта его именем файла.

Файл, созданный Connector, может не иметь захваченного блока производителя Python. **Никакого продюсерского блока**, **No review for this version**, **partial** среда и **ограниченный** доказательства являются значимыми состояниями, а не пробелами для заполнения сгенерированной прозой. Используйте [устранение неполадок](../guides/troubleshooting.md) для точных ошибок и этапов восстановления.

Ссылка на осуществление: [notebook.ts](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/notebook.ts), [Артефакты.ts](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/artifacts.ts), [WorkspaceMessageItem.tsx](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/WorkspaceMessageItem.tsx).

Для поддержки длительной работы следуйте [Справочные задачи и доставка результатов](../guides/notebook.md#background-tasks-and-result-delivery). Проверьте фактический запуск и сохраненные результаты после доставки. Окружающая среда и пакеты, настройка вычислительной среды и удаленные вычисления (SSH) остаются включенными, но их время выполнения, сеть и требования к хосту по-прежнему применяются.
