# Делегирование и Side Chat {/* #delegation-and-side-chat */}

Используйте Side Chat, чтобы обсудить вопрос вместе с текущей задачей или делегировать другому агенту отдельное задание. Чтобы продолжить полноценный разговор в другом направлении, используйте [ветку сессии](sessions.md).

## Side Chat {/* #side-chat-availability */}

### Когда использовать {/* #when-to-use-it */}

Откройте Side Chat, чтобы объяснить термин в результате анализа, сравнить два подхода или обсудить, как написать отчет. После обсуждения отправьте совет, который вы выберете для основного разговора, Main.

### Как использовать {/* #how-to-use-it */}

1. В существующем сеансе откройте **More send options → Side chat** рядом с кнопкой отправки. Вы можете открыть его с помощью пустого Композитора: сразу же появляется новый черновик Side Chat. Напишите вопрос там, проверьте модель и аргументацию, а затем отправьте его.
2. Прочтите ответ в независимой вкладке предварительного просмотра **Side chat**. Используйте **Side chat follow up**, чтобы задать больше вопросов. Вы можете вести несколько побочных обсуждений в рамках одной сессии и переключаться между их вкладками, продолжая использовать Main.
3. Чтобы поделиться советом с Main, попросите Side Chat передать его. Например: «Отправьте этот совет Main: Объясните недостающее значение обработки в отдельной части отчета». Проверьте сообщение с пометкой **Side chat** в Main. Если Main простаивает, отправьте следующий запрос на продолжение работы.
4. Используйте **Cancel Side chat response**, чтобы остановить текущий ответ. Чтобы сохранить обсуждение, оставьте вкладку открытой и перейдите на другую вкладку или сверните область предпросмотра.

Проект, содержащий текст или аннотации, выживает при переключении взглядов. Нетронутый пустой проект отбрасывается, когда вы покидаете его; Вскрытие проекта само по себе не посылает запрос модели.

### Перенос аннотации в нужный черновик {/* #move-an-annotation-to-the-right-draft */}

Для выбранного отрывка или региона используйте действие аннотации **Move to Side chat…** и выберите существующую сторону обсуждения или новую. Вы также можете перетаскивать аннотации между Main и черновиком Side Chat. Проверить пункт назначения и переданный контент перед отправкой: перемещение аннотации готовит черновик; Он не подает запрос.

Частные закладки **For me** - это другой инструмент для чтения. См. [Чтение закладок](bookmarks.md).

### Что нужно учитывать {/* #things-to-know */}

- **Настройки модели:** Новый Side Chat унаследовал основную модель разговора. Вы можете изменить их в Side Chat. Выбор распространяется на следующую отправку. Поддерживаются подписки Codex. Проверьте селектор перед отправкой.
- Обычные ответы **Передача и действия:** не отправляются в Main автоматически. Side Chat не может предоставлять разрешения Main; Подтвердите доставку, прежде чем просить Main принять меры.
- **Закрытие вкладки:** Прочитайте **Close Side chat?** перед подтверждением. Закрытие вкладки останавливает этот Side Chat и безвозвратно удаляет сохранённый разговор. Выберите **Cancel**, чтобы сохранить его, и перед закрытием передайте полезные советы Main или сохраненный отчет. Если уборка не удалась, вкладка возвращается; Проверьте ошибку перед повторным использованием.
- **Недоступный пункт:** Прочтите объяснение кнопки и устраните ожидающие одобрения, перенос вложений или восстановление сеанса. Проблемы с подключением см. [устранение неполадок](troubleshooting.md).

## Делегирование задач {/* #task-delegation */}

### Когда использовать {/* #when-to-use-it-1 */}

Делегатская работа, которая может быть выполнена независимо, например, проверка источников литературы, проверка файла данных или обзор результатов анализа, затем позволяет главному агенту объединить результаты. Для многоразовых помощников с определенными ролями см. [Делегация Specialist](../specialists/delegate.md).

### Как использовать {/* #how-to-use-it-1 */}

1. Проверьте **Delegation** в **Agent controls** Композитора.
2. В **Settings → Model → Subagent** выберите наследование из основной модели или настройте совместимую отдельную модель и усилие рассуждения.
3. Опишите задачу делегирования, ее входные файлы, ожидаемый выход и критерии принятия в вашем запросе.
4. Следуйте статусу подзадачи в записях активности и отвечайте на любые запросы на разрешение.
5. Откройте возвращенные файлы или исходные ссылки, чтобы проверить результат. Чтобы проверить записи исполнения, выберите соответствующего владельца в Notebook **Agent** фильтре.

### Что нужно учитывать {/* #things-to-know-1 */}

- Доступные возможности зависят от структуры и конфигурации агента. После предоставления возможности Делегации проверьте записи о деятельности, чтобы подтвердить, что подзадача действительно началась.
- Субагенты могут не разделять все контексты Main или переменные Python. Предоставьте файлы и инструкции, необходимые для выполнения задачи.
- Одобрение плана Main автоматически не одобряет все действия субагента. Проверьте конкретные действия и объем, когда требуется разрешение.
- Когда **Release** доступен, используйте его для завершения или выпуска ресурса подзадачи. Доказательства Main сохраняются.
