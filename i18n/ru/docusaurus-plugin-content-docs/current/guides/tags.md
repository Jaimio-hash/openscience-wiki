# Организация с тегами {/* #organizing-with-tags */}

Теги организуют **Skills, Коннекторы, Специалисты и ссылки**. Они не являются универсальной меткой на каждом сеансе или произвольном дисковом файле. Используйте **Settings → Tags** для создания тегов и просмотра назначенных ресурсов.

После назначения тега откройте его деталь и выберите перечисленный ресурс, чтобы вернуться к нему. Удаление назначения тега оставляет сам ресурс на месте.

## Создавать и редактировать {/* #create-and-edit */}

1. Откройте **New Tag**, введите имя и выберите его иконку и цвет.
2. Выберите **Create**. Проверьте новый ряд и состояние нулевого ресурса.
3. Выберите **Edit Tag** для повторного просмотра текущих значений. **Save** выполняет редактирование; **Cancel** отклоняет проект.

![Transcriptomics Tag Form (Транскриптомика)](/img/open-science/guides-walkthrough/30-tag-create.png)

| Поле/контроль | Варианты и поведение |
| --- | --- |
| Имя | Требуется; Имена уникальны независимо от случая. |
| Значок | Tag, Star, Bookmark, Flask, Book, Database, Code или Bot. |
| Цвет | Серый, красный, оранжевый, янтарь, зеленый, синий, фиолетовый или розовый. |
| Создать / Сохранить | создать новый тег или сохранить существующий тег; Пустые имена не могут быть предоставлены. |
| Отменить / Назад к тегам | Оставьте форму, не сохраняя ее текущий проект. |

Если сохранение возвращает **Не удалось сохранить тег**, сравните имя с существующими тегами, включая различия только для случая, и повторите с уникальным именем. Эта ошибка носит общий характер; Он сам по себе не устанавливает причину каждого неудачного спасения.

## Назначьте и найдите ресурсы {/* #assign-and-find-resources */}

Откройте предназначенные Skill, Connector, Specialist или Ссылку и используйте управление тегом для выбора тега. Вернитесь в Настройки → Теги и выберите строку тегов. Прочитайте количество ресурсов, а затем используйте **Filter resources by type** и **Search tagged resources** вместе. Селектор типа предлагает все ресурсы, Skills, Коннекторы, Специалисты и Справки. Поиск и сброс типа, если ожидаемый ресурс отсутствует.

В сборщике тегов ресурса, введите **Поиск тегов**, используйте **↑ / ↓** для перемещения по матчам и **Входить** для выбора. Если имя не существует, выберите **Создайте «имя»** для создания и присвоения. Проверьте выбранный тег после сохранения.

Одно только название тега не связывает услугу, не дает разрешения или не добавляет Skill Агенту. Эти средства контроля остаются на ресурсе и его потенциале.

<p className="example-label"><strong>Практический пример</strong> Найти архив Omics через тег Transcriptomics</p>

Назначьте **Транскриптомика** на **Архивы Omics**, затем откройте теги. В этом примере показан **Ресурс 1**; Поиск `Omics` сохраняет видимость Connector, и выбор его открывает его детали. Используйте свои собственные теги и имена ресурсов при повторении этих шагов. Удаление задания оставляет ресурс нетронутым.

![Назначенный Omics Archives ресурс найден через его тег](/img/open-science/guides-walkthrough/35-tagged-connector.png)

## Заказывайте список тегов {/* #order-the-tag-list */}

**Favorites** остается на первом месте Перетащите **Переупорядочивание &#91;имя&#93;** или сосредоточьте ручку и используйте клавиши со стрелками, чтобы переместить пользовательский тег. Проверьте свою новую позицию в списке.

![Заказ тегов и просмотр пустых ресурсов](/img/open-science/guides-walkthrough/31-tag-reorder.png)

## Удалить тег {/* #remove-a-tag */}

Выберите **Delete Tag** и проверьте **Назначения для удаления**. Удаление тега удаляет эти задания, но сохраняет ресурсы. **Cancel** сохраняет как тег, так и его назначения.

![Область удаления, отмененная в этом прохождении](/img/open-science/guides-walkthrough/32-tag-delete-boundary.png)

Если ваша цель состоит только в том, чтобы удалить одно задание, сделайте это на ресурсе, а не удаляйте тег везде. Использовать [Библиотека источников](./library.md) для организации документов в коллекции; Теги и коллекции служат разным целям.
