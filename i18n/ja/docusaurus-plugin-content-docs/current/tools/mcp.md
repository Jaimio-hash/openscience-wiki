# コネクタと MCP {/* #connectors-and-mcp */}

Connectorはエージェントが呼び出すことができるツールを公開します。 このページを使用して統合タイプを選択し、読みやすさを理解します。 フィールドバイフィールドの設定、インポート/エクスポートおよび接続管理については、[コネクターの構成](../guides/connectors.md) に従ってください。

## 接続タイプを選択してください {/* #choose-a-connection-type */}

| 型 | いつ使うか | 必須条件 |
| --- | --- | --- |
| 作り付け Connector | アプリケーションは既に必要なデータソースか操作を提供します | 意図したエージェントに有効化します。 一部のサービスは、認証情報も必要です。 |
| ローカルMCPサーバー | ツールは、このコンピュータ上で実行するか、ローカルで利用可能な研究データを読み込む必要があります | インストールされたランチャー、サーバーおよび許可された入力パス |
| リモート MCP サーバー | ホストされているMCPエンドポイントでツールを公開するサービス | 実際のMCPエンドポイント、サポートされたHTTP/SSE輸送および必要な認証 |

**Molecule**はローカル構造のレンダリングを提供します; リモートデータベースではありません。 [科学データベース](databases.md)のソースを選択するか、[科学ビューア](viewers.md)を使用して分子とシーケンスファイルを検査します。 Docker のランチャーを選択すると、コンテナエンジンやサーバーイメージはインストールされません。

## 可用性から接続を区別する {/* #distinguish-connection-from-availability */}

これらのステージを順番にチェックします。 次が成功したことは、誰も確立しません。

| ステージ | 確認する | 次のアクション |
| --- | --- | --- |
| 設定 | 正しいランチャーかエンドポイントおよび必須の認証 | 完了する [Connector フォーム](../guides/connectors.md) |
| コネクション | サーバが応答し、そのツールが発見される | 接続結果と実際のエラーを調べる |
| エージェントアクセス | Main または意図した Specialist に割り当てられたリソースが有効になっています。 | エージェントの能力バインディングをチェックする |
| 操作 | 選択したツールはリクエストを受け入れ、必要なデータを返す | 利用する [操作の参照](../reference/connector-operations.md) 組み込み入力用 |
| 研究結果 | 返された識別子、ソース、スコープはタスクにマッチします。 | 証拠としてそれを使用する前に応答を点検して下さい |

有効なスイッチは、成功したサービスコールではありません。 メタデータ応答は、ダウンロードしたフルテキストまたはカウントマトリクスではありません。 カスタム行は、設定エディタを開くことができます。 組み込みの細部は用具の指定を提供します。

## 失敗ステージを診断する {/* #diagnose-the-failing-stage */}

接続障害については、ランチャー、トランスポート、認証が失敗したかどうかを識別します。 接続が成功するが、コールが失敗した場合は、エージェントの可用性と、サーバーの設定を変更する前にそのツールの引数をチェックします。 [トラブルシューティング](../guides/troubleshooting.md) で返されたエラーを報告します。

接続中にMCPディスカバリーを実行します。 `host.mcp("server", "tools/list", {})`はアプリケーションツールコールではなく、**未知のツール**を返すことができます。 カスタム例では、`connector_unavailable` として内部の未知のサンプルの失敗も表しています。 その応答だけでは、輸送障害から無効なサンプルを区別しません。
