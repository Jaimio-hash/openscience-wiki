# 作り付けの研究用具 {/* #built-in-research-tools */}

組み込みの操作は、会話をプロジェクトファイル、Notebook実行、文献レコード、保存された結果に接続します。 それらは活動的な代理店のフレームワークを通して露出されます; インターフェイスは、**Agent SDK** または **Notebook** アクティビティ カードで複数の操作をグループ化できます。

## 研究タスクによるオペレーション {/* #operations-by-research-task */}

| ファミリー | サプライズ | 操作および目に見える結果 | 頼りになる前にチェック |
| --- | --- | --- | --- |
| ファイルの発見と読書 | プロジェクト/セッションと正確な入力 | アクセス可能なファイルをリストしたり、サポートされているコンテンツを読み込みます | フルネーム、ソース、現在のバージョン。 カタログの行はファイルコンテンツの検査ではありません |
| Notebook 実行 | Python/Rコード、ランタイムおよび有効な入力参照 | コードセル、出力、タイミング、実行状態 | 実際の言語/ランタイム、エラーと完全なデータチェック |
| アーティファクトの公開 | サポートされている出力パスまたはインラインコンテンツ | 会話/ファイルでバージョンアップされた結果カード | 出力を開き、寸法/コンテンツを比較し、バージョンを保持します。 |
| 文献検索/インポート | クエリ、DOI/PMID または参照ファイル | レコードの取得、受信トレイの候補とライブラリエントリ | ソース識別子、重複、レビュー決定、フルテキストアクセス |
| 計画業務 | 研究段階と完成基準 | セッションプランとステップ状態 | ステータスは実際に生成された出力にマッチします |
| メモリ | 再利用を目的とした事実または指示 | 設定されたスコープで保存されたメモリ | コンテンツとスコープ、プロジェクトファイルストレージから分離 |
| Skillローディング | 利用可能なパッケージID | 方法の指示とサポートリソース | 意図したパッケージが読み込まれました。 ローディングは計算しません |
| Specialistの代表団 | 役割、タスクおよび許可された入力 | 児童活動および補助物質の転写 | 実際に開始した子供は、要求されたチェックと報告された制限を実行します |
| 総説 | 適格な応答とレビュー構成 | 投稿者チェック、検索、補正状態 | どの応答/バージョンがレビューされ、どのような証拠が利用可能だったか |

## 結果から運用をフォローする {/* #follow-an-operation-through-to-its-result */}

1. 入力と希望の出力でリクエストを送信します。 [ファーストプロジェクト](../guides/first-project.md) は、小テーブルからリポートのタスクを フォローします。
2. 活動カードを拡大し、要求された操作、入力および許可の規模を点検して下さい。
3. 実行後、ツール結果を読みます。 エラーを解決する前に、その要約に頼る。
4. 生成されたファイルカードを開き、その内容を確認してください。 計算のために、作成コードおよびランタイムを点検するためにNotebookを開けて下さい。

[データ品質ワークフロー](../workflows/data-quality.md)は完全な科学的な例を供給します。 [Notebook](../guides/notebook.md) と [ランタイム](../guides/runtimes.md) で環境制御を解説します。

## ツールのアクティビティを読む {/* #read-tool-activity */}

| UI要素 | 使い方 |
| --- | --- |
| 活動グループ | 実行中にグループ化された操作を拡張します。 |
| ツール / エージェント SDK / Notebook 実行 | 利用可能な操作の詳細を開きます。 グループラベルではなく、入力、応答、エラーを読み取ります。 |
| コピーコード・コード開示 | 提出されたコードをコピーするか、または公開します。 2番目の実行を実行しません。 |
| 許可/認可の規模/拒否 | 表示された操作と選択されたスコープを制御します。 エージェントが要求するかどうかを調べます。 |
| 生成されたファイルカード | 保存した結果を開きます。 |
| Notebook を開く | セッションの実行レコードと変数を開きます。 |
| チャイルドタスクチップ | 実際の委任されたタスクを開きます。 独自のトランスクリプトを検査します。 |

## 一般的な入力/出力の混乱を避けて下さい {/* #avoid-common-inputoutput-confusion */}

アップロードされたファイル、Notebook 作業ファイル、およびアーティファクトバージョンは関連していますが、異なる。 1つのリストで表示されているファイルは、まだ子カーネルにマウントされていない可能性があります。 現行のアプリケーション認証の参照を使用してください。 パスを推測したり、そのファイル名でアーティファクトバージョンIDを置き換えたりすることで、使用不能な入力を修復しません。

Connector-createdファイルは、Pythonプロデューサーブロックをキャプチャしていない可能性があります。 **プロデューサーブロックなし**、**No review for this version**、**partial**環境および**バウンディング**の証拠は、生成された偽物に記入する空白ではなく、有意義な状態です。 正確なエラーと回復手順で[トラブルシューティング](../guides/troubleshooting.md)を使用してください。

実装参照: [ノートパソコン](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/notebook.ts)、[artifacts.ts(アーティファクト)](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/artifacts.ts)、[ワークスペースMessageItem.tsx](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/WorkspaceMessageItem.tsx)。

[背景タスクと結果配信](../guides/notebook.md#background-tasks-and-result-delivery) をフォローして、長時間の作業に対応しました。 納品後、実際の実行と保存した出力を調べます。 環境とパッケージ、環境設定とリモートコンピューティング(SSH)が有効になっていますが、ランタイム、ネットワーク、ホストの要件も適用されます。
