# ツールを探す {/* #explore-tools */}

必要な結果でツールを選択してください: レコードを検索し、ファイルを検査し、計算を実行するか、外部サービスを接続します。 このアプリケーションはこれらの機能を組み合わせていますが、異なるセットアップと証拠の要件があります。

## ツールファミリーを選ぶ {/* #choose-a-tool-family */}

| お問い合わせ | はじめに | 準備が整うべきこと | その後の検査について |
| --- | --- | --- | --- |
| ファイルを読む, 計画作業, 結果を計算または公開する | [作り付けの研究用具](./built-in.md) | アクセシブルなプロジェクト入力と運用許可 | ツール応答、出力ファイル、実行レコード |
| どの科学的なソフトウェアが方法を使用するか見つけて下さい | [科学ツールカタログ](./catalog.md) | パッケージ/重量をSkillインストールとは別にチェック | 実際の実行可能/インポートとバージョン |
| Python、Rまたは科学的なワークロードを実行します | [科学ツール](./scientific.md) | 選択されたランタイム、パッケージまたはコンピュートホスト | コード、エラー、出力チェック、および実証 |
| 生物医学的/科学的レコードの問い合わせ | [科学データベース](./databases.md) | Connector、ネットワークおよび必要な資格情報を有効にする | ソースID、返されたフィールドとトランチ |
| CSV、TSV、スプレッドシートデータを調べる | [テーブルとデータセット](./tables.md) | サポートされているファイルと現在の入力 | 目に見える行/列、区切り文字およびフルデータ次元 |
| ペーパー、シーケンス、構造および他の出力を読んで下さい | [科学ビューア](./viewers.md) | サポートされている形式 | レンダリングされたコンテンツと任意のプレビュー制限 |
| MCPサーバーを接続する | [コネクタと MCP](./mcp.md) | サーバー構成および信頼 | 接続された状態と実際のツール応答 |
| サービス ID/key の設定 | [サービス資格情報](./credentials.md) | 正しいサービスおよび使用可能なアカウント | バリデーション結果またはバインドされたライブクエリ |
| ツールでローカルデータを露出 | [カスタムMCPツール](./custom.md) | 入力スキーマのある作業サーバー | ディスカバリー、成功したコールと実際の失敗の動作 |

## 可用性にはいくつかの意味があります {/* #availability-has-several-meanings */}

**リスト** は、アプリケーションがリソースを把握することを意味します。 **Enabled** は、選択したエージェントがそれを使用する可能性があることを意味します。 **Connected** は Connector セッションを確認しますが、特定のクエリが有効であることを証明しません。 **実行する**は、実際に結果やエラーを返すツールを意味します。 **検証済み**は、その結果がタスクに対して検査されたことを意味します。

ローカル例には、実際の GSE60450 RNA-seq カウント、カスタム読み取り専用 QC サーバー、アスピリン分子アーティファクト、パブリックシーケンス/構造入力が含まれます。 両方の言語版で英語アプリケーションスクリーンショットを使用します。 リモート GPU/SSH の実行と、このデバイスで利用できなくなった認証情報は、完全なローカル操作から明示的に区別されます。

## エージェントにバインドされたリクエストを与える {/* #give-the-agent-a-bounded-request */}

ソース、操作、および期待される出力を指定します。 データベースのクエリには、識別子の名前空間と小さな結果の制限が含まれます。 計算のために、入力、選択された言語、チェックの名前をつけて下さい。 ツールが実行できない場合は、実際のエラーを尋ねます。 モデルメモリから再構築された答えは、成功したツールコールではありません。

[スキル](../skills/overview.md)は方法を供給します; [スペシャリスト](../specialists/overview.md)は再利用可能な役割を担います。 ソフトウェアを自動的にインストールし、資格情報を提供したり、アクセス不能なファイルを利用できるようにします。

実装参照: [コネクタパネル.tsx](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/settings/ConnectorsPanel.tsx)、[プレビューサポート.ts](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/preview-support.ts)。
