# 変更ログ・v0.25.1 {/* #changelog--v0251 */}

Open-Science [v0.25.1](https://github.com/aipoch/open-science/releases/tag/v0.25.1)には、次のユーザーフェーシングの変更が含まれます。 現在の操作手順については、リンクされた機能ガイドに従ってください。

## v0.25.1で何が変わったのか {/* #what-changed-in-v0251 */}

- 保護されたノートブックカーネルは、Windowsの直接サンドボックス起動パスを使用します。 ネットワーク保護は、アプリによって表示されているワンタイム管理者設定が必要です。
- ファイルとパッケージのエクスポートは、原子を公開します。 失敗したエクスポートは、部分的に書かれた宛先ファイルを残すべきではありません。 十分な空きスペースで、書き込み可能な目的地に再試行してください。
- 生成されたイメージのプレビューは再びレンダリングします。 画像がまだプレースホルダーを表示している場合は、アーティファクトの出版物を待ち、プレビューを再開し、ダウンロードをフォールバックとして使用してください。
- Skillsはカタログの矛盾を検出し、修理します。 中断されたSpecialistパッケージを交換する前に、任意のソース回復ガイダンスに従ってください。
- セッションの通貨、アーティファクト・フィナライゼーションの回復、PDF読書アイデンティティ、クロードの使用回復、および中断されたクリーンアップはより弾力性的です。 これらの修正はレコードを保存します。 科学的に検証されていない結果は作らない。

残りのセクションでは、このリリースで利用可能な機能がまとめられます。 以前の導入を識別する以下のバージョン履歴。

## セッション、インプット、ナビゲーションワークフロー {/* #session-input-and-navigation-workflows */}

### キュー、ステア、ブランチワーク {/* #queue-steer-and-branch-work */}

ターンが実行されている間、フォローアップを入力し、セッションキューに追加します。 キューの行は、編集、削除、再注文、またはすぐに送信することができます。 `Send now`は、アクティブなフレームワークのフォローアップチャネルを使用し、実行中のターンをキャンセルしません。 キュードドラフトは一時的であり、アプリが再起動したときに失われる可能性があるため、送信されるまで、重要な指示を他の場所に保存します。

`Branch in new session`は、その正確な点から続くために、完全なアシスタント応答で使用してください。 ブランチは、選択した応答を通じて会話とアクティビティの履歴をコピーしますが、プロンプトを送信しません。 コンフィギュレーション・チェンジ・ディバイダーは、後でフレームワーク、モデル、または推論効果の変更を識別します。

![長い会話でマークを実行](/img/open-science/v0.25.1/workspace-run-marks.webp)

デスクトップでは、ランマークのレールは、表示されたユーザープロンプトを表します。 プレビュー用のマークを非表示にしたり、ジャンプするマークを選択します。 標準のUndoは、アーカイブされたセッションまたは提供される変更草案を復元します。 `Cmd/Ctrl+Shift+Z` は、最新の作曲家のドラフト変更を赤くします。

### 参照セッションと大きな入力 {/* #reference-sessions-and-large-inputs */}

- `#` を入力し、読み取り専用のトランスクリプトコンテキストを 1 つのターンに添付するセッションを選択します。 結果のチップは、参照されたセッションに移動します。 参照は、別のプロジェクトへのアクセスを許可しません。
- 10,000 文字または 300 線上のプレーンテキストペーストが管理された添付ファイルになります。 `Show in text field`は、正確なテキストと注意を復元します。 送信前に添付カードを見直します。
- トランスクリプト、アクティビティ、またはテキストのプレビュー、または画像のポイントを選択し、注釈をコンテキストとして送信します。 アノテーションは、ソースで主張し、後で明らかにすることができます。
- セッションのタイトルと説明は、設定されたモデルができるようにする最初のメッセージから生成されます。 セッションコントロールからそれらを編集します。 マニュアル編集は、スーパーシード生成を編集します。

## ファイル、紙、および編集可能なアーティファクト {/* #files-papers-and-editable-artifacts */}

### エージェントでPDFを読みます {/* #read-pdfs-with-the-agent */}

PDF プレビューを開き、現在のセッションにリンクします。 PDFを3つまでリンクできます。 エージェントは、現在のページ、ドキュメントからページ、またはリンクされた論文を検索することができます。 テキストおよび長方形の選択は証拠の注釈になります; 証拠を選択すると、そのソース領域が明らかにされます。

選択したモデルに送信される可能性のある用紙のみをリンクします。 PDF コンテキストは読み取り専用とバージョンアップですが、外部プロバイダは抽出されたコンテンツを受け取ることができます。 後で有効にするために利用できなくなった場合、文書のリンクを解除します。

### テキストアーティファクトの編集と比較 {/* #edit-and-compare-text-artifacts */}

Markdown、プレーンテキスト、スクリプト、および認証されたソースコードのアーティファクトまたはアップロードの場合:

1. ファイルのプレビューを開き、ファイルアクションから`Edit`を選択します。
2. ソースを編集し、保存します。
3. 新しい管理されたバージョンが公開されるのを待ってから、`Compare` を使用して、その前任者に対してそれを検査します。
4. 前/次バージョンでナビゲートし、結果を引用する前にProvenanceを調べます。

各保存は新しいバージョンを作成します。 前の証拠は書き換えません。 バイナリ文書、画像、ノートブック、その他未サポートのフォーマットは、読み取り専用のままです。 リビジョン・コンフリクトは、コンピュレーション・バージョンをリロードし、ブラインドを上書きするのではなく比較します。

![Version-scopedのアーティファクトの実績](/img/open-science/v0.25.1/artifact-provenance.webp)

エージェントレスポンス HTTPS ソースはサンドボックスのサイドプレビューで開きます。 外部に開く前に表示されるURLを確認してください。 プレビューの分離はリスクを減らしますが、未知のサイトを信頼できるものにしません。

## Notebookおよび計算制御 {/* #notebook-and-compute-controls */}

- `Variables` は、Python または R の名前空間を、名前、種類、形状、および境界線のプレビューで表示します。 読み込み専用で、実行後にリフレッシュし、単に閲覧のためにカーネルを起動しません。 ターミナルは、ライブ変数名を示唆しています。 リクエストがない限り、個人名は隠されています。
- クロスラン依存解析は、以前の変数変更後、`stale`、`clear`、または`unknown`を出力します。 `unknown` を再実行する必要があるように扱います。
- 設定 → ネットワークは、Notebook のドメイン許可リストを管理し、実行時間を計算します。 ブロックされた宛先は、 `Deny`, , `Allow once`, または `Always allow`. . . . 一度の承認は、正確なコマンドに適用されます。 バウンダリは、非関連なシステムプロセスではなく、アプリのランタイムをカバーします。
- 各セッションでは、コンピュートホストと選択した実行対象が有効になっています。 Composer のコンピュート コントロールを使用して、設定されたホストを選択します。 パスワード認証は、オペレーティングシステムの認証サービスを通じて保存されます。 SSHキーまたは実用的なエージェントを好む。
- 設定→ランタイムは、カーネルをドレインした後、健康なアプリ管理PythonまたはRランタイムを再インストールすることができます。 外部通訳者は、その行動によって修復されることはありません。 エージェント・クリエイト・エンビロンメント・スイッチは、明示的なセットアップや再インストールをブロックしません。

## 機能とアカウント設定 {/* #capabilities-and-account-settings */}

- 設定には、メモリ、タグ、認証情報、および使用方法を含む17パネルが含まれています。 メモリは、オプトインおよびプロジェクトスコープ付きです。 秘密を保存するのではなく、エントリを検査、修正、削除します。
- タグは、Skills、コネクタ、およびカタログを渡るスペシャリストを整理します。 お気に入りは保護され、最初に残っています。 他のタグは再注文することができます。
- Credentials は、デバイス全体キー、アクセストークン、OAuth サインインを保存します。 カスタム コネクタは、認証情報を環境変数またはヘッダーにバインドし、プレーンテキストをポータブルエクスポートにコピーすることなく。
- Connector の輸入/輸出は標準的な `mcpServers` JSON を支えます。 輸出された秘密とヘッダーは、`${NAME}`プレースホルダーになります。 OAuth クライアントの事前登録はクライアント ID と書き込み専用のクライアントシークレットを受け付けます。 発行者またはクライアント ID の変更は、バインディングを無効化します。
- Specialistマーケットプレイスは、署名されたパッケージを検証します。 マーケットプレースコンテンツは読み取り専用です。 アップデートは、インストールされたベースラインに対してSemVerを事前に設定する必要があります。 パッケージのソースを見直して下さい、取付けの前にSkillsおよびコネクターを含んでいました。
- モデル設定には、メイン、サブエージェント、レビュアー、ビジョン、およびセッションディテールの作業のためのシナリオポリシーが含まれます。 CodeBuddyは、Claude Code、OpenCode、Codex と共に利用できます。 プロバイダーのカタログには、xAIのサブスクリプション、テンセントのプラン、OpenCodeのGo/Zen、NVIDIAビルドが含まれます。 インストールされたピッカーの可用性は、許可されています。
- 利用パネルは、プロバイダーがそれらを報告したときにターンとモデルの呼び出しを分離し、委任、サイドチャット、コンパミネーション、セッションディーテール生成などの補助コールを属性にします。 プロバイダーのテレメトリーが不完全なカバレッジとして表示され、推定使用量ではありません。
