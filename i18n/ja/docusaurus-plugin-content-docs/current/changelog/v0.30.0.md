# 変更ログ・v0.30.0 {/* #changelog--v0300 */}

9月 15, 2026 リリース このアップデートでは、読書と並行的な議論を整理するためのツールを追加し、設定を行い、PDFの証拠を抽出しやすくなります。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.30.0) · [v0.29.0から変更](https://github.com/aipoch/open-science/compare/v0.29.0...v0.30.0)

## 新規および更新されたワークフロー {/* #new-and-updated-workflows */}

| 特集記事 | 使い方 |
| --- | --- |
| プライベートブックマーク | 会話またはプレビューテキスト、またはPDF領域を選択し、選択する **For me**オプションのメモでブックマークを保存します。 リターン・スルー **Bookmarks** セッションで。 これらのメモはエージェントのコンテキストを入力しません。 [読書ブックマーク](../guides/bookmarks.md) |
| 独立したSide Chatタブ | Mainの横にいくつかの議論を開いたままにしてください。 送信前に意図した草案に注釈を移動します。 確認する **Close Side chat** チャットを停止し、保存された会話を永久に削除します。 [Side Chat](../guides/delegation.md) |
| 設定センター | 下のパネルを見つけて下さい **Intelligence**, **Connections**, **Workspace** そして、 **System**ヘッダーの検索を使用して、パネルに移動します。 [設定の概要](../settings/overview.md) |
| 全体検索 | 開く **Advanced filters** スコープ、順序、時間および結果固有のフィルタを調整するカテゴリの横にある。 カラムがフィルタを適用するのを促す。 [ナビゲーションと検索](../guides/navigation.md) |
| 抽出されたPDFの証拠 | PDFをリンクし、それを分析します **Figures and tables**. エージェントは、キャッシュされた数値、テーブル、アルゴリズムをリストして読み込むことができます。 [PDF 証拠](../guides/previews.md#pdf-agent-evidence) |
| プロバイダのカタログ | SenseNovaの提供 **中国の中国** そして、 **Global** 地域。 フレームワークとアカウントがサポートする無料のゲートウェイエントリが利用できます。 [プロバイダーのセットアップ](../guides/providers.md#provider-regions) |

## 改善と修正 {/* #improvements-and-fixes */}

- セッションホバーの詳細には、セッション番号が含まれます。 Skill、ConnectorおよびSpecialistのバッチ制御は一貫した行為区域を使用します。
- PDFは、回転されたページ上のネイティブフィギュア/テーブルの回復とテキスト選択を改善します。 抽出はまだソースに対してチェックする必要があります。
- Connectorは、dbSNP削除アレル、正しいVEPアレルハンドリングと一意のトランスクリプトカウントを保存し、排除されたBioMart booleanフィルタを修復します。
- アイドルの背景ワークを削減。 進捗状況、ランタイム回復メッセージ、Windowsシェルハンドリング、結果配信、アプリケーションシャットダウンは、信頼性の修正を受け取ります。

## 新しいワークフローを使用する前に {/* #before-using-the-new-workflows */}

ブックマークは1つのセッション内に残り、`.science`のエクスポートとクロスマシンの同期から除外されます。 インポートされた研究パッケージは、読み取り専用のままです。 Reproducibility は、選択した保存バージョンをまだチェックします。 セッション全体を再生しません。 [研究パッケージ](../guides/research-packages.md) と [再現性](../guides/reproducibility.md) は、該当するワークフローを参照してください。

[インストールと更新](../guides/installation.md) を使用してアプリを更新します。 [v0.29.0](./v0.29.0.md)では初期変更が残っています。

[v0.30.1](./v0.30.1.md) は、次のリリースを続けてください。
