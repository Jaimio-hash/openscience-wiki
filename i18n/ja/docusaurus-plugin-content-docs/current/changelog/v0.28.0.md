# 変更ログ・v0.28.0 {/* #changelog--v0280 */}

9月 11, 2026 リリース このバージョンでは、保存された結果の記録された手順を再実行し、出力を比較するチェックを追加します。 また、グローバル検索を拡大し、リモートメディアの読み込みを明示します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [v0.27.0から変更](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## 新しい機能 {/* #new-features */}

### 保存した結果が再現されているかどうかをチェックする {/* #check-whether-a-saved-result-reproduces */}

**Reproducibility**は、キャプチャされたファイルバージョンの入力、実行記録、および環境情報を使用して、分離の手順を再実行します。 チェックを開始する前に必要な証拠を調べ、各出力の比較結果を確認します。 チェックは1つのバージョンまたはバージョンのバッチをカバーでき、レコードはエクスポートできます。

完了した実行は単独で出力の一致を意味しません。 証拠やサポートされていない操作を見逃すと、チェックを防ぐことができます。 この機能は、キャプチャされたバージョンをチェックします。 セッション全体を再生しません。 チェックを開始すると、デスクトップインターフェイスが要求され、大きなRDS / H5ADファイルがコンテンツの比較には読み込まれません。 [特徴の細部](../guides/reproducibility.md).

### 一緒にメッセージ、ファイル、文献を検索する {/* #search-messages-files-and-literature-together */}

グローバル検索では、プロジェクト、セッション、メッセージテキスト、アップロードおよび生成されたファイル、およびライブラリレコードおよびコレクションが含まれます。 カテゴリと関連するフィールドでフィルタリングし、コンテキストを調べる結果を選択し、マッチングメッセージまたはファイルを開きます。 サポートされているテキストファイルの内容は検索可能です。 これは、すべてのバイナリフォーマットのフルテキストのインデックス化を阻害しません。

各カテゴリ内でのさらなるマッチをグループ化しました。 結果の間に移動しながら、細部のペインは開いたままにすることができます。 [変更の検索](../guides/navigation.md).

### アプリ管理Codexランタイムの更新 {/* #update-an-app-managed-codex-runtime */}

エージェントの設定は、ACP アダプターバージョンのネイティブ Codex CLI バージョンを区別します。 古いアプリ管理インストールは、テストされたペアに明示的な更新を受け取ることができます。 外部にインストールされたCLIは、手動メンテナンスを必要としています。 交換前に実行時間を使用してタスクを終了または停止します。 これはOpen-Science自体を更新することとは別です。 [Runtime 更新の詳細](../guides/frameworks.md#update-codex).

### WindowsでWSL2 Bashを試す {/* #try-wsl2-bash-on-windows */}

Windows x64 は、オプションの **WSL2バッシュプレビュー** を獲得します。 PowerShell はデフォルトのままです。 プレビューを使用するには、明示的なアクティベーション、マッチングアセット、成功した準備チェックが必要です。 通常のWindows使用の前提条件ではありません。 [プレビュースコープ](../guides/runtimes.md#wsl2-preview).

## 既存の設定に影響を及ぼす変更 {/* #changes-that-affect-existing-setups */}

| 範囲 | 期待するもの |
| --- | --- |
| リモートモデル接続 | リモートエンドポイントでは、HTTPS が必要です。 既存のリモートHTTPの設定は編集可能であり、修正されるまで実行できません。 HTTP は localhost および loopback アドレスに対してサポートされます。 |
| 応答のメディア | 遠隔画像、音声およびビデオは活発化のための待っています。 ローディングの前に目的地のホストを点検して下さい; 権限は、表示された要素に適用されます。 |
| モデルに送信された画像 | モデル入力コピーには、任意のメタデータが削除されます。 元のファイルは保存されます。 |

これらの変更は、古いメッセージを表示または再利用する際にも適用されます。 [接続とメディアの変更](https://github.com/aipoch/open-science/pull/2420).

コンダ、PyPI および CRAN ミラーのホストはパッケージ管理操作のために一時的に承認されます。 これは、永久的なNotebookのパーミッションを追加したり、他のホストにリダイレクトを自動的に許可しません。 また、使用不能なミラーやDNSの無効な応答を解決しません。 [パッケージのミラーの変更](../guides/network.md).

## 改善と修正 {/* #improvements-and-fixes */}
