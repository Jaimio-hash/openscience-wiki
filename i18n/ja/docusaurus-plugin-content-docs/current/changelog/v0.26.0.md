# 変更ログ・v0.26.0 {/* #changelog--v0260 */}

Open-Science [v0.26.0](https://github.com/aipoch/open-science/releases/tag/v0.26.0)には、次のユーザーフェーシングの変更が含まれます。 現在の操作手順については、リンクされた機能ガイドに従ってください。

## Main ワークフロー {/* #main-workflows */}

### 文献ライブラリ {/* #literature-reference-library */}

新しいローカルリファレンスライブラリは、個々のPDFとBibTeX、RIS、またはNBIBレコードをインポートします。 コレクションやプロジェクトへの参照を整理します。 重複を見つけます。 選択したオープンアクセスPDFを添付します。 リビジョンの実証とフォーマットの引用. Agent-discovered リファレンスは、ライブラリをサイレントに結合するのではなく、Inbox を入力します。 [文学ライブラリー](../guides/library.md) を参照してください。

### リモートコンピューティングのためのSlurm実行 {/* #slurm-execution-for-remote-compute */}

SSH ホストには **Execution mode**: **Direct SSH** または **Slurm** があります。 Slurmモードは、スケジューラ所有のジョブを提出し、耐久性のある状態を投票し、中断後に回復し、スケジューラをキャンセルし、ステージされたファイルをクリーンアップします。 組み込みの**コンピューティング環境設定**スキルは、選択したホストのセットアップ、修理、および削除の指示を生成します。 自分でレビューしたり、クラスター管理者に送信したりします。

![リモートホストの実行モード](/img/open-science/v0.26.0/compute-slurm-mode.png)

`sbatch`が存在するためだけSlurmを選択しないでください。 ログインホストポリシー、パーティション/アカウント/ QoSのデフォルト、スクラッチパス、モジュールまたは環境設定、壁時間制限、およびキャンセルルールを確認します。 Open-Scienceは、クラスターまたは付与スケジューラアクセスを提供していません。

### 読み取り可能なツールと承認カード {/* #readable-tool-and-approval-cards */}

アーティファクトは、一般的なノートブックは、生のJSONの代わりに、コンパクトなサマリーカードとしてレンダリングを制御します。 正確な引数、パス、バージョン、または実行状態の問題時にカードを拡大します。 Skill-load承認カードは、決定前に完全な`SKILL.md`を拡張することができます。

![承認でSkill文書を拡大](/img/open-science/v0.26.0/skill-approval-expanded.png)

### プロバイダーおよびモデルカタログ {/* #providers-and-model-catalogs */}

Apodex は `apodex-1.1` および `apodex-1.1-mini` が付いている作り付けの提供者として利用できます。 バンドルされたカタログには、GPT-6 AstraとClaude Fable 5.1も含まれます。 カタログエントリは、資格情報、アクセス、または容量を提供していません。 インストールされたピッカーと成功した接続テストは権威です。

## その他のユーザー表示変更 {/* #other-user-visible-changes */}

- **許可:** ルーチン読み取り専用ノートブック/ランタイム検査、メモリルックアップ、パッケージ在庫、および承認されたプランの進捗状況の更新には、より安全なデフォルト付与があります。 グラントは、設定で表示され、取り消すことができます。
- **プレビューメニュー:** は、プレビューコンテンツを右クリックして、パスをコピーしたり、ダウンロードしたり、ローカルファイルをアーティファクトとして保存したりします。 管理されたアーティファクトは、実証済みの操作と返り対のコンテキストアクションを公開することができます。
- **タスクAPI:** CLI、HTTP、SDK クライアントは、プロンプトを送信せずに、セッションのモデル、推論努力、メモリ設定、およびコンピュートホスト選択を検査または更新することができます。
- **大きい Skills:**は、数千ものファイルを含むインポートは、境界線、高速パスを使用し、パッケージの完全性チェックを保持します。
- **信頼性:**ストリーミング、長セッションリソース使用、計画の回復、更新処理、ノートブックランタイム、アーティファクトの出版物、永続性、プロバイダの状態、資格情報、リモートアクセス、ストレージの移行、およびアクセシビリティが回復と是正を受け取りました。

## ブレイクタスクSDK変更 {/* #breaking-task-sdk-change */}

公開タスクSDK契約からレガシーセッションプランの継続フィールドが削除されました。 クライアントは、サポートされている API を通じて、現在のセッションと計画状態を読み取ります。 アップグレードする前に、古いフィールドを優先する統合をテストします。 この変更は、通常のデスクトップの会話ではなく、API消費者に影響を与えます。
