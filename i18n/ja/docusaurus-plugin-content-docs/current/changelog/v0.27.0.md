# 変更ログ・v0.27.0 {/* #changelog--v0270 */}

このリリースは、文献のインポートを拡大し、背景の実行を追加し、研究セッション全体で回復を改善します。 また、CLI および SDK のユーザーに対して、アプリケーションに必要な Skills を有効にして Connector 管理を追加します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.27.0) · [v0.26.0から変更](https://github.com/aipoch/open-science/compare/v0.26.0...v0.27.0)

## 新しい機能 {/* #new-features */}

### 複数のPDFを一緒にインポートする {/* #import-several-pdfs-together */}

複数の PDF を選択すると、ファイル選択、保存先の要約、識別子の一致ポリシー、進捗状況、ファイルごとの結果が 1 つのインポート ダイアログが開きます。 **Stop**はそれ以上の処理を終わらせます; **Retry unfinished**は未完成品を再開します。 単一のPDFを選択すると、メタデータエディタのルートが保持されます。

一致する参照を再利用するかどうかを選択し、別のレコードを保持するか、空のフィールドを埋めます。 ライブラリは、検索フィルタの独立して活動的な合計を表示し、検出されたDOIからメタデータを豊かにすることができます。 抽出されたタイトルと識別子をチェック: 完了したインポートは正しいメタデータを保証するものではありません。 [文学ライブラリと引用](../guides/library.md) を参照してください。

![2つのPRISMAのペーパーが付いているバッチPDFの輸入](/img/open-science/v0.27.0/02-pdf-batch-ready.webp)

### タスクの実行中に作業を継続 {/* #continue-working-while-tasks-run */}

Python, R, 永続性REPL, シェルの作業はバックグラウンドで実行できます。 セッションは、タスクのアイデンティティ、ステータス、経過時間、キャンセルを追跡します。 **Open** は対応する実行に戻ります。 ローカルランとリモートコンピュートジョブの会話に自動的に結果が配信されます。

完了後に保存したファイルを調べます。 リモートジョブは、構成されたホストと適切なリソースを必要とします。 [バックグラウンドタスク](../guides/notebook.md#background-tasks-and-result-delivery) を参照してください。

![ローカルの背景タスクを完了](/img/open-science/v0.27.0/13-background-task-completed.webp)

### 適用 Skillsを利用できる保って下さい {/* #keep-application-skills-available */}

**Customize**, **環境・パッケージ**, **リモートコンピューティング(SSH)**, **コンピューティング環境設定** が有効になりました。 チェックされた、無効なスイッチは、オフにできない理由を説明しています。 内部サポートSkillsも使用可能です。 ディレクトリにパブリックメソッドを追加していません。

これは、科学的依存性をインストールしたり、Specialistへのアクセスを許可しません。 スキルのワークフローとして保存する [必須 Skills](../skills/overview.md#why-some-switches-cannot-be-turned-off) と [Skill を作成する](../skills/create.md) を参照してください。

### スクリプトから統合を管理する {/* #manage-integrations-from-scripts */}

CLIとTask SDKは、カスタムConnector管理とともに、Connectorの発見、点検および有効/無効な制御を追加します。 ヘッドレスLinuxは、OSクレデンシャルボルトが利用できなくなったときに、明示的なファイルベースのクレデンシャルストレージオプションも得ます。 OS ストレージはデフォルトのままです。 ファイルストアは暗号化されていないため、ファイルシステムアクセス制御を介して保護する必要があります。

[Connector CLIコマンド](../reference/cli.md#manage-connectors-and-credentials)、[SDK メソッド](../reference/api.md#connector-management-methods)、[Linuxクレデンシャルストレージ](../reference/server.md#credential-storage-on-headless-linux) をご覧ください。

## 互換性と既知の問題 {/* #compatibility-and-known-issues */}

リリースには、CodexサブスクリプションSide Chatの起動を修正し、バックエンドで再開する[#2394](https://github.com/aipoch/open-science/pull/2394)が含まれています。 同じタグ付けされたデスクトップコードは、メニューエントリを無効にするプロバイダのガードを保持します。 そのソースビルトデスクトップの新鮮なチェックは、このガードに達しました。 サポートの意図的な欠如ではなく、調査とエンドツーエンドの検証を必要とするUI /バックエンドの矛盾としてこれを追跡します。 [Side Chat 利用可能](../guides/delegation.md) を参照してください。

[v0.29.0](./v0.29.0.md)でこのデスクトップのエントリーガードが削除されました。 上記の制限は、v0.27.0 ソースに属しています。

インストールまたは更新については、[インストールと更新](../guides/installation.md)を参照してください。 [v0.26.0](./v0.26.0.md)では初期変更が残っています。
