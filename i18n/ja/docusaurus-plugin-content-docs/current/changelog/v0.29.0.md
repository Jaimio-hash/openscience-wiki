# 変更ログ・v0.29.0 {/* #changelog--v0290 */}

9月 13, 2026 リリース このバージョンでは、Skillの発見、ポータブルリサーチレコード、ローカルPDF図/テーブル抽出を追加します。 また、Codex Side Chatと外部Rパッケージのサポートも更新します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [v0.28.0から変更](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## 新しい機能 {/* #new-features */}

### 市場からSkillsを発見し、インストールする {/* #discover-and-install-skills-from-the-marketplace */}

**Marketplace**のカテゴリ、著者、および利用可能な評価の詳細をブラウズし、その後、そのカードからSkillをインストールします。 アップデートは、明示的な確認が必要です。 バッチ管理はろ過された選択、順次取付けを支えま、現在の項目の後で停止し、失敗を再試行します。

カタログとパッケージは、署名された配布レコードに対してチェックされます。 これは、配布アイデンティティを確立します。 方法の適性を点検するか、または研究の依存性を準備する取り替えません。 [マーケットプレースの詳細](../skills/marketplace.md).

### .scienceパッケージで研究履歴を転送する {/* #transfer-research-history-in-a-science-package */}

アイドルセッションを**.science**パッケージとしてエクスポートします。 **エッセンシャル**はデフォルトのエクスポートスコープです。 **ふるさと** と追加の制御には、ファイル、バージョン、および再現された出力を含むことができます。 プロジェクトメニューをインポートし、パッケージをプロジェクトにドロップするか、関連するファイルを開き、プレビューを調べて、宛先を確認します。

インポートされたセッションは、検査と参照のための研究履歴と証拠を保存します。 それらは読み取り専用です: 実行と継続は無効です。 別のインストールから受け取った検証レコードは、受信コンピューターで実行されているチェックではなく、ソースのアサーションが残っています。 [パッケージの動作](../guides/research-packages.md).

### ローカルでPDFから図と表を抽出する {/* #extract-figures-and-tables-from-a-pdf-locally */}

**Figures and tables** ワークフローは、検証済みのモデルリソースをインストールし、PDF をローカルに分析します。 キャッシュされた結果を再開し、図をコピーまたはダウンロードし、表をHTML、TSVまたはMarkdownとしてエクスポートします。

抽出されたコンテンツをソースページと比較します。, 特に結合されたヘッダー, 脚注とコンテンツの交差ページ. 未解決のテキストとレビュー警告は表示されません。 抽出されたテーブルは、分析の前にチェックを要求します。 [PDF抽出の細部](../guides/previews.md#pdf-extraction).

### パッケージを外部のR環境にインストールする {/* #install-packages-into-an-external-r-environment */}

外部のR環境では、既存の、書き込み可能な個人的なRライブラリのパッケージインストールの同意を得ることができます。 対象となるライブラリを選択し、**Allow package install**を有効にします。 システムおよびサイトライブラリは除外されます。 同意を取り消すことができます。

必要な依存性ロックが存在する場合、外部のRとPython環境は、条件付きパッケージ修復の証拠を提供することもできます。 復元には、マッチング前提条件とユーザー実行の復元スクリプトが必要です。 パッケージを修復することは、研究結果が再現することを証明するだけでなく、それ自体ではありません。 [Rインストールと復元条件](../guides/runtimes.md#external-r-packages).

## 改善と修正 {/* #improvements-and-fixes */}

| 範囲 | 変更内容 |
| --- | --- |
| Codex Side Chat | グローバルプロバイダーがCodexサブスクリプションを使用したときにエントリをブロックした古いデスクトップガードを削除しました。 セッション状態と回復条件は、エントリが利用できなくなったままにすることができます。 [詳細](https://github.com/aipoch/open-science/pull/2460) |
| コネクタ | 設定は、一括有効/無効に対応しています。 文献グラフは、クロスラフの作業/更新の検索とDataCiteの記録/研究方法を追加します。 Rfamシーケンス検索は、修復されたバッチエンドポイントを使用します。 [経営管理](https://github.com/aipoch/open-science/pull/2507), [データメソッド](https://github.com/aipoch/open-science/pull/2509) |
| CLIとSDK | ランタイムリスト/インストール、ターミナルプロファイルの初期化、Codex ファーストランセットアップを追加しました。 これらは、既存のアプリケーション・バックされた CLI を拡張します。 [ランタイム](https://github.com/aipoch/open-science/pull/2489), [初期化](https://github.com/aipoch/open-science/pull/2474), [Codex セットアップ](https://github.com/aipoch/open-science/pull/2487) |
| タスクのダウンロード | 完成したタスクの出力をダウンロードすると、アーティファクトのバージョン ID を保存し、HTTP 500 の原因を修復します。 [ダウンロードの修正](https://github.com/aipoch/open-science/pull/2490) |

その他の変更は、起動を改善します。, 更新レトリー, Windows 動作回復, 文献メタデータと科学 Skill 処理. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.29.0) は、完全なリストを参照してください。

インストールについては、[インストールと更新](../guides/installation.md)を参照してください。 [v0.28.0](./v0.28.0.md)では初期変更が残っています。
