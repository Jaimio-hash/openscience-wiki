# タグを整理する {/* #organizing-with-tags */}

タグ 整理 **Skills、コネクター、スペシャリストおよび参照**. それらは、すべてのセッションまたは任意のディスクファイル上の普遍的なラベルではありません。 **Settings → Tags** を使用して、タグを作成し、割り当てられたリソースをブラウズします。

タグを割り当てた後、詳細を開き、リストされたリソースを選択して返します。 タグの代入を削除すると、リソース自体が所定の場所に残されます。

## 作成と編集 {/* #create-and-edit */}

1. **New Tag** を開き、名前を入力し、そのアイコンと色を選択します。
2. **Create** を選択します。 新しい行とゼロリソースの状態を確認します。
3. **Edit Tag** を選択して、現在の値を再訪します。 **Save** は編集をコミットします。 **Cancel** はドラフトを破棄します。

![Transcriptomicsタグフォーム](/img/open-science/guides-walkthrough/30-tag-create.webp)

| フィールド/コントロール | オプションと動作 |
| --- | --- |
| 名前 | 必須; いずれにしても名前は一意です。 |
| アイコン | タグ, スター, ブックマーク, フラスコ, ブック, データベース, コードまたはボット. |
| 色 | 灰色、赤、オレンジ、アンバー、緑、青、パープルまたはピンク。 |
| 作成/保存 | 新しいタグを作成するか、既存のタグの編集を保存します。 空名は提出できません。 |
| キャンセル/タグに戻る | 現在のドラフトを保存せずにフォームを残します。 |

**タグを保存できませんでした** を節約する場合は、ケースのみの差を含む既存のタグと名前を比較し、一意の名前をリトライします。 そのエラーは汎用的です。 それはそれ自体がすべての失敗した保存の原因を確立することによってではないです。.

## リソースの割り当てと検索 {/* #assign-and-find-resources */}

意図したSkill、Connector、Specialistまたはリファレンスを開き、タグコントロールを使用してタグを選択します。 &#91;設定&#93; → &#91;タグ&#93; に戻り、タグの行を選択します。 リソースのカウントを読んで、**Filter resources by type**と**Search tagged resources**を一緒に使用してください。 タイプセレクターは、すべてのリソース、Skills、コネクタ、スペシャリスト、および参照を提供します。 期待するリソースが欠落している場合、タイプをクリアしてリセットします。

リソースのタグピッカーでは、**タグを検索** に入力し、**↑ / ↓** を使用してマッチと **エントリー** を選択して移動します。 名前が存在しない場合は、**「名前」を作成する** を選択して作成して割り当てます。 保存後に選択したタグを確認してください。

タグ名だけは、サービス、付与権限を接続したり、Skillをエージェントに追加したりしません。 これらの制御は資源および機能結合に残ります。

<p className="example-label"><strong>実践例</strong> TranscriptomicsタグでOmicsのアーカイブを見つける</p>

**トランスクリプトオミクス** を **Omics アーカイブ** に割り当て、タグの詳細を開きます。 この例では、**1リソース** が表示されます。 `Omics` を検索すると、Connector が表示され、その詳細が開きます。 これらのステップを繰り返すときに独自のタグとリソース名を使用します。 代入を取り戻すと、リソースをそのまま残します。

![タグから発見されたOmicsのアーカイブリソースを割り当てる](/img/open-science/guides-walkthrough/35-tagged-connector.webp)

## タグリストを注文する {/* #order-the-tag-list */}

**Favorites** は、最初に滞在します。 **注文する &#91;名前&#93;**をドラッグするか、ハンドルを集中して矢印キーを使用して、カスタムタグを移動します。 リスト内の新しい位置を確認してください。

![タグの注文と空のリソースビュー](/img/open-science/guides-walkthrough/31-tag-reorder.webp)

## タグを削除 {/* #remove-a-tag */}

**Delete Tag** を選択し、**削除する課題** を検査します。 タグの削除は、それらの割り当てを削除しますが、リソースを保持します。 **Cancel** はタグとその代入の両方を保持します。

![削除スコープ、このウォークスルーでキャンセル](/img/open-science/guides-walkthrough/32-tag-delete-boundary.webp)

目的が1つの割り当てを削除するだけであれば、タグをどこにでも削除するのではなく、リソースでそれを行います。 [文献ライブラリ](./library.md) を使用して、紙をコレクションに整理します。 タグとコレクションは、異なる目的のために役立ちます。
