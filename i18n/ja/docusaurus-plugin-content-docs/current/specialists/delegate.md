# 作業の委任と検証 {/* #delegate-and-verify-work */}

Main Agent が会話を調整する一方で、Delegation は別々の子タスクをロールに与えます。 Specialist を選択すると、メインの会話と子供タスクの委任は異なるアクションです。

## 拘束されたハンドオフを用意する {/* #prepare-a-bounded-handoff */}

| 必須情報 | 例 |
| --- | --- |
| プロフィール | RNA-seq QCの査読装置、保存されたID `rna-seq-qc-reviewer` |
| 入力 | 完全なGSE60450サンプルQC CSV、か有効な現在のimmutableファイル版 |
| タスク | 12 の非従順なフルサンプル ID と per-sample の gene-count の ID をチェックします。 |
| 配送可能 | 1つのチェックテーブルとすべてのサンプルの演算結果 |
| クーポン | 読み取り専用; 新しいパッケージはありません。 差圧解釈なし |

1. [インフォメーション](./identity.md) を作成/設定し、有効になっていることを確認します。
2. **Agent controls**の会話では、**Delegation**を有効にします。 意図したモデルと作業認証を確認します。
3. Main エージェントに明示的に委任し、役割を識別し、完全なタスクを提供するよう依頼してください。 ファイルハンドオフを使用する場合は、アプリが現在のバージョンを解決してみましょう。 ID を発明したり、ファイル名をバージョン参照として渡したりしないでください。
4. 実際の委任活動と子供のステータスを監視します。 Main Agent の進捗状況は、子レコードではありません。
5. 子供の破片/**Subagents**の下検分を開けて下さい。 **Subagent Frame** のタスクを選択し、トランスクリプト、ツール結果、端末の状態を読み込みます。
6. スコープを調べた後、親の会話で任意の子の許可要求に対応します。 その後、要求された受諾チェックで返された結果を比較します。

## ハンドオフと返された結果をチェックする {/* #check-the-handoff-and-returned-result */}

### 小さなインラインテーブルをチェックする {/* #verified-example-twelve-sample-invariants */}

<p className="example-label"><strong>実践例</strong> 12サンプルテーブルチェックを解除する</p>

完全な<ExampleDownload path="/examples/gse60450/rnaseq-sample-qc.csv">サンプルQC CSV</ExampleDownload>をダウンロードし、要求のすぐ下にあるすべての12列をヘッダーと貼り付けます。 すべての列を保ち、サンプル識別子を完成させます。 例では、[Specialist アイデンティティ](identity.md) で作成された有効なロールを使用します。 Pythonは、その算術のために有効にする必要があります。 このバインドチェックにはSkillは必要ありません。

> RNA-seq QC レビュアーに委任して下さい。 下記の完全なインラインCSVだけを使用して下さい。 Pythonで算数を実行し、12個の異なるフルサンプル識別子を検証し、zero_count_genes + detected_genes_count_gt_0 = 27179を各行ごとにチェックします。 各結果とこのチェックが供給されたサマリーデータが、元のカウントマトリクスへの独立したアクセスではない状態に戻ります。

![完成したSpecialistサブタスクと1サンプルチェック](/img/open-science/capabilities-walkthrough/15-specialist-delegated-result.jpg)

この例では、子供はPython Notebookを実行し、**12 行、12 は非従順な識別子を区別し、12/12 は 27,179 に等しい合計します**を返す。 最初のフルサンプルIDの場合、`8,664 + 18,515 = 27,179`。 数値フィールドが完成し、非ネガティブであった。

これにより、供給されたサマリーの一貫性が確認されます。 元の行列から合計/メディアを独自に再現したり、サンプル条件を検証したり、生物学的品質閾値を確立したりすることはできません。

<span id="check-file-handoff-and-a-separate-model" />

### 別のモデルを選ぶ {/* #choose-a-separate-model */}

Main の子モデルを独自にセットします。



**Settings → Model → Subagent** の下の固定モデルを選ぶ前に委任します。 実際のモデルを検証するために、子供レコードを開きます。 主要な会話のモデルラベルは子供を識別しません。 Main は、`gpt-5.6-sol` と、`gpt-5.6-luna` の子実行レコードを使って、Codex のサブスクリプション認証を通した。

### 子にファイルを渡す {/* #pass-a-file-to-the-child */}

<p className="example-label"><strong>例</strong> 子の仕事にサンプルQCファイルを渡して下さい</p>

1. 会話の添付メニューからソースファイルを添付し、アップロードが完了するまで待ちます。
2. Main をリクエストして、アップロードしたバージョンを子供に渡します。 必須チェックと出力名 ファイル名やファイル用の推測されたバージョンIDを代入しません。
3. **Subagents** を開き、子供を選択します。 **Notebook** では、**Agent** フィルタの子を選択し、実際のファイルの読み込みを検査します。
4. 子の行数、列名、チェックサムをソースと比較します。 保存された出力を開き、要求された計算を確認してください。

[パブリックサンプルメトリック CSV](/examples/gse60450/portable-script/remote-rnaseq-qc-f1e10edbdf01-f1e10edbdf01.csv)では、**12データ列**と**269,027,617**を`total_counts`の合計として期待しています。 入力チェックサムは変更されなければいけません。 これらのチェックは、供給されたサンプル要約に関心を寄せています。 元の gene-count の行列を再計算しません。

| チェックイン | 必須の証拠 |
| --- | --- |
| 受け入れられる版 | このアプリは、現在のimmutableアップロード/アーティファクトバージョンを独自のセッションで解決しました。 |
| 子供は読むことができます | 子のツールは、ファイルの内容を返す。 ファイル名やステージドパスだけでは不十分です。 |
| チェック実行 | 子は計算を実行し、保存された結果はソースに同意します。 |

アプリケーションが利用できなくなった入力を報告する場合、そのファイルを再添付し、現在のバージョンを使用して再試行します。 子が**`PermissionError: [Errno 1] Operation not permitted`**を報告した場合、再添付が読み出しを回復しない場合は、正確なエラーと[報告する](../guides/troubleshooting.md)を保持します。 ファイルを内部のアプリケーションフォルダに移動してエラーを迂回しないでください。

### Skillを子供に利用できるようにする {/* #make-a-skill-available-to-the-child */}

Skillを最初にインポートまたは作成します。 Specialist では、その役割の [Skillsおよびコネクター](capabilities.md) の下に割り当てます。 その後、メソッドを明示的に名前付ける新しい委任されたタスクを開始します。 お子様がインストールした指示を読んで、使用する前に必ずお読みください。

ロードされたSkill IDとコンテンツの子のツールアクティビティを調べます。 例えば、`rnaseq-count-qc`は生の遺伝子計算の行列を要求し、記述的なQCを記述します; 12列のサンプル要約は交換可能な入力ではありません。 成功したパッケージ読み取りは、分析が実行されているという意味ではありません。 実行および保存された結果を別々にチェックします。

## 不具合を正確に読み込む {/* #read-failures-accurately */}

| 観察またはサポートされた状態 | 意味と回復 |
| --- | --- |
| デリゲーションオフ | 再試行の前に意図した会話のためにそれをオンにします。 |
| 役割の無効化/セットアップの不完全 | 設定を完了し、意図された保存されたロールを有効にします。 |
| このセッションで利用できない入力 | 正確な現在のアーティファクトバージョンまたは不変なアップロードバージョンリファレンスを取得します。 パス、アーティファクトID、バージョンIDは異なる値です。 |
| 許可を待っています | 名前付き子供の保留操作を点検して下さい; Main エージェントは、コンピューティングではなく待機しているかもしれません。 |
| チャイルド完成 | 結果とツールの証拠を読んでください。 科学的矯正の保証はありません。 |
| キャンセル/失敗 | 部分的な出力と実際のエラーを保持します。 Main エージェントの交換を完成した Specialist チェックとしてラベル付けしないでください。 |

インラインルートは、証拠のスコープが記載されている完全で縛られたテーブルのみに適しています。 ファイルリネンの一般的な交換ではありません。
