# Cambios · v0.28.0 {/* #changelog--v0280 */}

Publicado en septiembre 11, 2026. Esta versión añade cheques que reimprimen el procedimiento grabado de un resultado guardado y comparan la salida. También expande la búsqueda global y hace explícita la carga de los medios remotos.

[Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [Cambios desde v0.27.0](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## Nuevas características {/* #new-features */}

### Compruebe si un resultado guardado se reproduce {/* #check-whether-a-saved-result-reproduces */}

**Reproducibility** utiliza las entradas de una versión de archivo capturada, el registro de ejecución y la información del medio ambiente para volver a ejecutar su procedimiento en forma aislada. Inspeccione las pruebas requeridas antes de iniciar un cheque, luego revise el resultado de comparación de cada salida. Los cheques pueden cubrir una versión o un lote de versiones, y sus registros pueden ser exportados.

Una ejecución completa por sí sola no significa que las salidas coincidan. La falta de pruebas o de operaciones no apoyadas puede prevenir un cheque. Esta característica comprueba las versiones capturadas; no vuelve a reproducir una sesión entera. Iniciar un cheque requiere la interfaz de escritorio, y los archivos RDS/H5AD grandes no se cargan para la comparación de contenidos. [Detalles de la función](../guides/reproducibility.md).

### Buscar mensajes, archivos y literatura juntos {/* #search-messages-files-and-literature-together */}

La búsqueda global ahora incluye proyectos, sesiones, texto de mensajes, archivos cargados y generados, y registros y colecciones de la Biblioteca. Filtrar por categoría y campos relevantes, seleccionar un resultado para inspeccionar su contexto, y luego abrir el mensaje o archivo que coincida. Los contenidos compatibles con los archivos de texto se pueden buscar; esto no implica la indexación de texto completo de cada formato binario.

Los resultados agrupados cargan más partidos dentro de cada categoría. El panel de detalles puede permanecer abierto mientras se mueve entre los resultados. [Cambios de búsqueda](../guides/navigation.md).

### Actualizar un tiempo de ejecución Codex gestionado por aplicaciones {/* #update-an-app-managed-codex-runtime */}

Los ajustes de los agentes distinguen la versión Codex CLI nativa de la versión de adaptador ACP. Una instalación administrada por aplicaciones más viejas puede recibir una actualización explícita al par probado. Los CLI instalados externamente todavía requieren mantenimiento manual. Terminar o detener tareas utilizando el tiempo de ejecución antes de reemplazarlo; esto es separado de la actualización Open-Science en sí. [Detalles de actualización de tiempo de ejecución](../guides/frameworks.md#update-codex).

### Prueba WSL2 Bash en Windows {/* #try-wsl2-bash-on-windows */}

Windows x64 gana un **WSL2 Bash Preview**. PowerShell sigue siendo el predeterminado. Utilizar la vista previa requiere activación explícita, emparejando activos y cheques de preparación exitosos; no es un requisito para el uso ordinario de Windows. [Alcance de vista previa](../guides/runtimes.md#wsl2-preview).

## Cambios que afectan a las configuraciones existentes {/* #changes-that-affect-existing-setups */}

| Área | Qué esperar |
| --- | --- |
| Conexións de modelos remotos | Los puntos finales remotos requieren HTTPS. Las configuraciones HTTP remotas existentes siguen siendo editables pero no pueden ejecutarse hasta que se corrija. HTTP sigue siendo compatible con direcciones localeshost y de vuelta. |
| Medios de comunicación en respuestas | Imágenes remotas, audio y vídeo esperan la activación. Inspeccione el destino anfitriones antes de cargar; la autorización se aplica a ese elemento mostrado. |
| Imágenes enviadas a un modelo | Las copias de entrada de modelos se eliminan de metadatos auxiliares; los archivos originales se conservan. |

Estos cambios también se aplican al ver o reutilizar mensajes antiguos. [Cambios de conexión y medios de comunicación](https://github.com/aipoch/open-science/pull/2420).

Los anfitriones de espejo Conda, PyPI y CRAN están autorizados temporalmente para la operación de gestión de paquetes. Esto no añade permisos Notebook permanentes o autoriza automáticamente redirecciones a otros hosts. Tampoco resuelve un espejo no disponible ni una respuesta DNS inválida. [Cambios en el espejo del paquete](../guides/network.md).

## Mejoras y correcciones {/* #improvements-and-fixes */}

Las actualizaciones mejoran la verificación del instalador y el comportamiento de reingreso. Otras correcciones cubren la puesta en marcha Windows R, metadatos PubMed, persistencia de sesión y recuperación de fallos. Compruebe el [liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.28.0) para la lista completa.

Para la instalación, vea [Instalar y actualizar](../guides/installation.md). Continuar a [v0.29.0](./v0.29.0.md), o revisar [v0.27.0](./v0.27.0.md).
