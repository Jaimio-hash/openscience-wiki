# 更新日誌 · v0.25.1 {/* #更新日志--v0251 */}

Open-Science [v0.25.1](https://github.com/aipoch/open-science/releases/tag/v0.25.1) 包含以下使用者功能更新。當前操作方法以連結的功能教程為準。

## v0.25.1 的變化 {/* #v0251-的变化 */}

- Windows 受保護 Notebook 核心 改用直接沙箱啟動路徑；網路保護仍需完成應用提示的一次性管理員設定。
- 檔案與包匯出改為原子釋出。匯出失敗不應留下半成品；請改用可寫且空間充足的目標後重試。
- 生成圖片的預覽已恢復。若仍顯示佔位符，先等待 產物釋出，重新開啟預覽，必要時使用 Download。
- Skills 會檢測並修復 catalog 不一致。恢復中斷的專家包時，應先閱讀來源提示再替換。
- 會話併發、產物釋出、PDF 閱讀身份、Claude 用量恢復與中斷清理更可靠；這些修復保留記錄，但不會自動證明研究結論正確。

以下章節彙總該版本已具備的能力；更早版本引入的功能見下方版本歷史。

## 會話、輸入與導航 {/* #会话输入与导航 */}

### 排隊、引導和分支工作 {/* #排队引导和分支工作 */}

執行中的輪次 可以繼續輸入並加入會話佇列。佇列項可編輯、刪除、排序或 `Send now`；後者透過當前框架的 follow-up 通道傳送，不會取消正在執行的輪次。佇列草稿在重啟後可能丟失，重要指令應在發出前另行儲存。

在已完成的智慧體回覆上選擇 `Branch in new session`，可從該節點新建會話；系統複製截至該回復的對話與活動記錄，但不會自動傳送提示詞。配置分隔線會標記 框架、模型或推理強度 的變化。

![長對話中的執行標記](/img/open-science/v0.25.1/workspace-run-marks.webp)

桌面端的 run-marks rail 每個標記對應一條可見使用者提示詞；懸停或聚焦可預覽，選擇後跳轉。Undo 可恢復介面明確支援的歸檔或草稿操作，`Cmd/Ctrl+Shift+Z` 重做最近一次 Composer 草稿變化。

### 引用會話與較大輸入 {/* #引用会话与较大输入 */}

- 輸入 `#` 選擇另一會話，可在當前輪次 中附加其可見對話記錄 的只讀上下文；它不會跨專案授權。
- 超過 10,000 字元或 300 行的純文字貼上會變成託管附件；`Show in text field` 可還原原文與游標位置。
- 可選擇 對話記錄、活動或預覽 中的文字，或圖片上的點，並作為批註 發給智慧體；批註會保留來源。
- 首條訊息可生成會話標題與描述；手動編輯會覆蓋仍在進行的生成。

## 檔案、論文與可編輯產物 {/* #文件论文与可编辑产物 */}

### 與智慧體閱讀 PDF {/* #与智能体阅读-pdf */}

PDF 預覽 最多可把三份 PDF 連結為當前會話的閱讀上下文。智慧體可讀取當前頁、翻頁或搜尋；文字與矩形選擇會形成 證據批註，之後可返回原位置。只應連結允許傳送給當前模型的論文；不用時及時 unlink。

### 編輯和比較文字產物 {/* #编辑和比较文本产物 */}

Markdown、純文字、指令碼和已識別的原始碼 產物或上傳檔案 支援編輯：

1. 開啟檔案預覽，在 File actions 中選擇 `Edit`。
2. 編輯 源文字 並儲存。
3. 等待新託管版本釋出，再用 `Compare` 與前一版本對照。
4. 使用 Previous/Next version 導航，並在引用前檢查 Provenance。

每次儲存都會建立新版本，不會改寫舊證據。二進位制文件、圖片、Notebook 等不支援的格式仍為只讀。出現 版本衝突 時應重新載入並比較，而不是盲目覆蓋。

![按版本記錄的 產物來源證據](/img/open-science/v0.25.1/artifact-provenance.webp)

智慧體回覆中的 HTTPS 來源可在 隔離側邊預覽 開啟。外部開啟前檢查顯示的 URL；隔離預覽並不代表未知站點可信。

## Notebook 與計算控制 {/* #notebook-与计算控制 */}

- `Variables` 只讀展示正在執行的 Python/R 變數空間，包括名稱、型別、形狀 與受限預覽；檢視不會為了瀏覽而啟動核心。終端會提示實時變數名，私有變數名預設隱藏。
- 跨執行依賴分析把舊輸出標為 `stale`、`clear` 或 `unknown`；`unknown` 應按需要重新執行處理。
- Settings → Network 管理 Notebook 與 計算執行環境 的 域名允許列表。被阻止的目標可選擇 `Deny`、`Allow once` 或 `Always allow`；一次性授權只適用於該命令。邊界不覆蓋應用外的系統程序。
- 每個會話分別儲存 enabled compute hosts 與 selected execution targets；透過 Composer 計算控制元件選擇已配置主機。密碼由作業系統憑據服務儲存，條件允許時優先使用 SSH key 或 ssh-agent。
- Settings → Runtimes 可在停止相關核心 後重灌 應用管理的 Python/R 執行環境，不會修改外部直譯器。禁止智慧體建立環境並不影響使用者顯式 setup 或 reinstall。

## 能力與賬戶設定 {/* #能力与账户设置 */}

- 設定現有 17 個面板，包括 Memory、Tags、Credentials 與 Usage。Memory 為 預設關閉，啟用後按專案隔離；不要把 金鑰寫入記憶。
- Tags 可跨 Skills、Connectors 與 Specialists 分類；Favorites 受保護並固定在首位。
- Credentials 統一儲存裝置級 key、access token 與 OAuth sign-in。Connector 可將命名憑據繫結到環境變數或 header，portable export 只保留 `${NAME}` 佔位符。
- Connector import/export 支援標準 `mcpServers` JSON。預註冊 OAuth client 可填寫 client ID 與只寫 client secret；更改 issuer 或 client ID 會使繫結失效。
- Specialist Marketplace 驗證簽名包；Marketplace 內容只讀，更新必須提升 SemVer。安裝前檢查來源、Skills 與 Connectors。
- 模型設定包含 main、subagent、reviewer、vision 與 session-details 策略。CodeBuddy 與 Claude Code、OpenCode、Codex 並列；實際可用 provider 以安裝版本中的 picker 為準。
- Usage 在 provider 上報足夠資料時區分 turns 與 model calls，並計入 delegation、side chat、compaction、session details 等輔助呼叫；缺失資料會顯示覆蓋不足。
