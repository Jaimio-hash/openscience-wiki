# 更新日誌 · v0.28.0 {/* #更新日志--v0280 */}

釋出於 2026 年 9 月 11 日。本次更新支援根據已儲存結果的執行記錄重新執行並比較輸出，同時擴充套件全域搜尋，並要求使用者主動載入回覆中的遠端媒體。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [與 v0.27.0 的完整差異](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## 新增功能 {/* #新增功能 */}

### 檢查已儲存的結果能否復現 {/* #检查已保存的结果能否复现 */}

**Reproducibility** 根據某個檔案版本記錄的輸入、執行過程和環境資訊，在隔離環境中重新執行。開始前先檢查所需證據，完成後逐項檢視輸出比較結果。可以檢查單個版本，也可以批次檢查多個版本，並匯出檢查記錄。

執行完成不等於輸出一致。證據缺失或操作不受支援時，檢查可能無法繼續。這項功能針對已捕獲的檔案版本，不會重放整個會話。發起檢查需要桌面介面，大型 RDS/H5AD 檔案不會被載入進行內容比較。見[功能說明](../guides/reproducibility.md)。

### 一起搜尋訊息、檔案與文獻 {/* #一起搜索消息文件与文献 */}

全域搜尋現在覆蓋專案、會話、訊息正文、上傳與生成的檔案，以及文獻庫條目和集合。可以按類別及相關欄位篩選，選擇結果檢視上下文，再開啟對應訊息或檔案。支援搜尋適用文字檔案的內容，但不表示所有二進位制格式都能全文檢索。

分組結果可以在各類別內繼續載入。切換結果時，詳情面板可以保持開啟。見[搜尋更新](../guides/navigation.md)。

### 更新應用管理的 Codex 執行時 {/* #更新应用管理的-codex-运行时 */}

Agent 設定分別顯示原生 Codex CLI 和 ACP 介面卡的版本。較舊的應用管理安裝可以顯式更新到經過測試的組合；外部安裝的 CLI 仍需自行維護。替換前應完成或停止正在使用該執行時的任務。這與更新 Open-Science 應用本身是兩項操作。見[執行時更新說明](../guides/frameworks.md#update-codex)。

### 在 Windows 試用 WSL2 Bash {/* #在-windows-试用-wsl2-bash */}

Windows x64 新增可選的 **WSL2 Bash Preview**，預設仍使用 PowerShell。使用預覽功能需要主動啟用、版本匹配的資源及透過就緒檢查；日常使用 Windows 版不要求先配置它。見[預覽功能範圍](../guides/runtimes.md#wsl2-preview)。

## 影響現有配置的變化 {/* #影响现有配置的变化 */}

| 範圍 | 使用時的變化 |
| --- | --- |
| 遠端模型連線 | 遠端端點必須使用 HTTPS。已有遠端 HTTP 配置仍可編輯，但更正前不能執行。localhost 與迴環地址仍支援 HTTP |
| 回覆中的媒體 | 遠端圖片、音訊和影片等待主動載入。載入前檢視目標主機，授權只針對當前顯示的媒體元素 |
| 傳送給模型的圖片 | 模型輸入副本會移除附加後設資料，原始檔案保留 |

檢視或複用舊訊息時也會應用這些規則。見[連線與媒體變化](https://github.com/aipoch/open-science/pull/2420)。

已配置的 Conda、PyPI 和 CRAN 映象主機會在本次包管理操作中獲得臨時授權。這不會增加永久 Notebook 權限，也不會自動授權跳轉後的其他主機；映象不可用或 DNS 返回無效地址的問題仍需分別處理。見[包映象更新](../guides/network.md)。

## 改進與修復 {/* #改进与修复 */}

更新流程改進了安裝包校驗和重試處理。其他修復涉及 Windows R 啟動、PubMed 後設資料、會話儲存和故障恢復。完整列表見[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.28.0)。

安裝步驟見[安裝與更新](../guides/installation.md)。繼續閱讀 [v0.29.0](./v0.29.0.md)，或回看 [v0.27.0](./v0.27.0.md)。
