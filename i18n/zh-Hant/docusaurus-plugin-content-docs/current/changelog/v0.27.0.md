# 更新日誌 · v0.27.0 {/* #更新日志--v0270 */}

本次更新擴充套件了文獻匯入能力，加入後臺執行，並改進研究會話的恢復處理。應用必需的 Skills 保持啟用，CLI 與 SDK 也增加了 Connector 管理能力。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.27.0) · [與 v0.26.0 的完整差異](https://github.com/aipoch/open-science/compare/v0.26.0...v0.27.0)

## 新增功能 {/* #新增功能 */}

### 批次匯入 PDF {/* #批量导入-pdf */}

選擇多份 PDF 後，在同一個匯入視窗檢查檔案選擇、目標位置、識別符號匹配策略、進度和逐檔案結果。**Stop** 停止後續處理，**Retry unfinished** 重試尚未完成的選中項。只選擇一份 PDF 時，仍進入後設資料編輯器。

遇到相同識別符號時，可選擇複用已有文獻、保留獨立條目或補充空欄位。文獻庫總數獨立於搜尋篩選顯示，並可根據識別出的 DOI 補充後設資料。匯入完成後仍需檢查標題與識別符號；完成狀態不保證後設資料準確。詳見[文獻庫與引用](../guides/library.md)。

![兩份 PRISMA 論文的批次 PDF 匯入](/img/open-science/v0.27.0/02-pdf-batch-ready.webp)

### 將長任務放到後臺執行 {/* #将长任务放到后台执行 */}

適用的 Python、R、持久 REPL 和 Shell 工作可在後臺執行。會話跟蹤任務身份、狀態、耗時和取消操作；**Open** 開啟對應執行記錄。本地執行和遠端 Compute 作業的結果可自動送回對話。

完成後應檢查實際儲存的檔案。遠端作業仍需配置主機並具備合適資源，詳見[後臺任務](../guides/notebook.md#后台任务与结果送达)。

![已完成的本地後臺任務](/img/open-science/v0.27.0/13-background-task-completed.webp)

### 保持應用必需 Skills 可用 {/* #保持应用必需-skills-可用 */}

**Customize**、**Environment & Packages**、**Remote Compute (SSH)** 和 **Compute Environment Setup** 保持啟用。開關為選中且禁用狀態，並提供不可關閉的原因提示。內部支援 Skill 也保持可用，但不作為公開目錄中的額外研究方法。

此規則不會安裝科學軟體依賴，也不會授予 Specialist 訪問權限。見[必需 Skills](../skills/overview.md#为什么有些开关不能关闭)及[建立 Skill](../skills/create.md)中的 Save as skill 流程。

### 透過指令碼管理整合 {/* #通过脚本管理集成 */}

CLI 和 Task SDK 增加 Connector 列表、詳情及啟用/禁用操作，並提供自定義 Connector 管理能力。無可用系統憑據庫的無介面 Linux 環境可在啟動時顯式選擇檔案憑據儲存；預設仍使用系統儲存。檔案儲存不加密，需要透過檔案系統權限保護。

詳見 [Connector CLI](../reference/cli.md#管理-connector-与凭据)、[SDK 方法](../reference/api.md#connector-管理方法)和 [Linux 憑據儲存](../reference/server.md#linux-无界面服务的凭据存储)。

## 相容性與已知問題範圍 {/* #兼容性与已知问题范围 */}
