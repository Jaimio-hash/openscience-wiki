# 更新日誌 · v0.30.0 {/* #更新日志--v0300 */}

釋出於 2026 年 9 月 15 日。本次更新增加了整理閱讀記錄和並行討論的工具，並改善設定查詢和 PDF 提取結果的使用方式。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.30.0) · [與 v0.29.0 的完整差異](https://github.com/aipoch/open-science/compare/v0.29.0...v0.30.0)

## 新增與更新的使用流程 {/* #新增与更新的使用流程 */}

| 功能 | 如何使用 |
| --- | --- |
| 私人書籤 | 選擇對話或預覽文字，或框選 PDF 區域，選擇 **For me**，儲存書籤並按需新增備註。從會話的 **Bookmarks** 返回原處；這些備註不會進入 Agent 上下文。[閱讀書籤](../guides/bookmarks.md) |
| 獨立 Side Chat 標籤頁 | 在 Main 旁保留多個討論，把批註移入指定草稿後再傳送。確認 **Close Side chat** 會停止該旁聊並永久刪除其儲存的對話。[Side Chat](../guides/delegation.md) |
| 設定中心 | 按 **Intelligence、Connections、Workspace、System** 查詢面板，或使用頂部搜尋定位設定。[設定中心總覽](../settings/overview.md) |
| 全域搜尋 | 點選類別旁的 **Advanced filters**，調整範圍、排序、時間和對應結果型別的篩選。收起篩選欄後，已選條件仍然生效。[導航與搜尋](../guides/navigation.md) |
| PDF 提取證據 | 連結 PDF，並在 **Figures and tables** 完成分析後，Agent 可以列出和讀取已快取的圖、表及演算法內容。[PDF 證據](../guides/previews.md#pdf-agent-evidence) |
| 模型提供商目錄 | SenseNova 提供 **China** 和 **Global** 區域；框架與賬號支援時，可選擇目錄中的免費閘道器模型。[模型接入](../guides/providers.md#provider-regions) |

## 改進與修復 {/* #改进与修复 */}

- 會話懸停詳情增加會話編號；Skill、Connector 和 Specialist 的批次操作使用一致的操作區。
- 改善 PDF 原生圖表佈局恢復，並修復旋轉頁面的文字選區。提取結果仍需對照原文檢查。
- 資料介面修復涵蓋 dbSNP 刪除等位基因保留、VEP 等位基因處理與唯一轉錄本計數，以及 BioMart 布林篩選的排除條件。
- 減少空閒時的後臺工作，改善更新進度顯示、執行環境恢復提示、Windows 終端操作、結果交付和應用退出的穩定性。

## 使用前需要了解 {/* #使用前需要了解 */}

書籤屬於單個會話，不隨 `.science` 研究包匯出，也不跨機器同步。匯入的研究包仍為只讀；可復現性檢查仍針對選定的儲存版本，不會重放整個會話。對應流程見[研究包](../guides/research-packages.md)和[可復現性](../guides/reproducibility.md)。

更新應用請參閱[安裝與更新](../guides/installation.md)。此前變化見 [v0.29.0](./v0.29.0.md)。

後續變化見 [v0.30.1](./v0.30.1.md)。
