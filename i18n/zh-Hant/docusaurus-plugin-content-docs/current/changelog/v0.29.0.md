# 更新日誌 · v0.29.0 {/* #更新日志--v0290 */}

釋出於 2026 年 9 月 13 日。本次更新增加了 Skill 發現、研究記錄傳遞和本地 PDF 圖表提取能力，並更新了 Codex Side Chat 與外部 R 包安裝支援。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [與 v0.28.0 的完整差異](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## 新增功能 {/* #新增功能 */}

### 從市場發現與安裝 Skills {/* #从市场发现与安装-skills */}

在 **Marketplace** 瀏覽分類、作者和可用的評估詳情，然後從卡片安裝 Skill。更新版本需要顯式確認。批次管理支援按篩選結果選擇、順序安裝、完成當前項後停止，以及重試失敗項。

目錄和軟體包會依據帶簽名的分發記錄進行校驗。這能確認分發身份，但不能代替判斷方法是否適用，也不會替你準備科研依賴。見[市場功能說明](../skills/marketplace.md)。

### 用 .science 包傳遞研究記錄 {/* #用-science-包传递研究记录 */}

可以將空閒會話匯出為 **.science** 包。預設使用 **Essential** 匯出範圍；**Full** 和其他選項可以包含更多檔案、版本與復現輸出。透過 Project 選單匯入、將包拖入專案，或開啟關聯檔案後，先檢查預覽，再確認目標專案。

匯入的會話保留研究歷史與證據，供檢視和引用。它是隻讀記錄，不能執行或繼續對話。隨包收到的驗證記錄仍屬於來源端的驗證宣告，不表示接收電腦已重新檢查。見[研究包說明](../guides/research-packages.md)。

### 在本地提取 PDF 圖表 {/* #在本地提取-pdf-图表 */}

可選的 **Figures and tables** 流程會安裝經過校驗的模型資源，並在本地分析 PDF。之後可以重新開啟快取結果、複製或下載圖片，以及將表格匯出為 HTML、TSV 或 Markdown。

使用前應對照原文頁檢查提取內容，尤其是合併表頭、腳註和跨頁內容。未解析的文字與待核對提示會保留，提取出的表格仍需核對後再用於分析。見 [PDF 提取說明](../guides/previews.md#pdf-extraction)。

### 在外部 R 環境中安裝包 {/* #在外部-r-环境中安装包 */}

外部 R 環境現在可以獲得針對已有、可寫的個人 R 庫的安裝授權。選擇合適的庫後啟用 **Allow package install**；系統庫和站點庫不在授權範圍內，已有授權也可以撤銷。

具備所需依賴鎖檔案時，外部 R 和 Python 環境還可提供有條件的包恢復證據。恢復需要滿足匹配條件，並由使用者執行恢復指令碼。恢復軟體包本身不代表研究結果已復現。見 [R 安裝與恢復條件](../guides/runtimes.md#external-r-packages)。

## 改進與修復 {/* #改进与修复 */}

| 範圍 | 變化 |
| --- | --- |
| Codex Side Chat | 移除了全域提供方使用 Codex 訂閱時禁用桌面入口的舊判斷。會話狀態和恢復條件仍可能導致入口不可用。見[修復說明](https://github.com/aipoch/open-science/pull/2460) |
| Connectors | 設定支援批次啟用/禁用。Literature Graph 增加 Crossref 文獻及更新查詢、DataCite 條目及搜尋方法；Rfam 序列搜尋改用修復後的批次端點。見[管理更新](https://github.com/aipoch/open-science/pull/2507)、[資料查詢更新](https://github.com/aipoch/open-science/pull/2509) |
| CLI 與 SDK | 增加執行時列表及安裝、終端配置初始化和 Codex 首次設定能力，繼續使用依託應用執行的 CLI。見[執行時](https://github.com/aipoch/open-science/pull/2489)、[初始化](https://github.com/aipoch/open-science/pull/2474)、[Codex 設定](https://github.com/aipoch/open-science/pull/2487) |
| 任務檔案下載 | 保留產物的版本身份，修復了已完成任務下載輸出時返回 HTTP 500 的一類原因。見[下載修復](https://github.com/aipoch/open-science/pull/2490) |

其他變化改善了啟動速度、更新重試、Windows 操作恢復、文獻後設資料及科研 Skill 處理。完整列表見[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.29.0)。

安裝步驟見[安裝與更新](../guides/installation.md)，更早的變化見 [v0.28.0](./v0.28.0.md)。
