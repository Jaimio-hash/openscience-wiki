# Changelog · v0.29.0

Released September 13, 2026. This version adds Skill discovery, portable research records and local PDF figure/table extraction. It also updates Codex Side Chat and external R package support.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.29.0) · [Changes since v0.28.0](https://github.com/aipoch/open-science/compare/v0.28.0...v0.29.0)

## New features

### Discover and install Skills from the marketplace

Browse categories, authors and available assessment details in **Marketplace**, then install a Skill from its card. Updates require explicit confirmation. Batch management supports filtered selection, sequential installation, stopping after the current item and retrying failures.

Catalogs and packages are checked against signed distribution records. This establishes their distribution identity; it does not replace checking a method's suitability or preparing its research dependencies. [Marketplace details](../skills/marketplace.md).

### Transfer research history in a .science package

Export an idle session as a **.science** package. **Essential** is the default export scope; **Full** and additional controls can include more files, versions and reproduced outputs. Import through a Project menu, drop a package into a Project, or open the associated file, then inspect the preview and confirm the destination.

Imported sessions preserve research history and evidence for inspection and reference. They are read-only: execution and continuation are disabled. Verification records received from another installation remain that source's assertions, not checks performed on the receiving computer. [Package behavior](../guides/research-packages.md).

### Extract figures and tables from a PDF locally

The optional **Figures and tables** workflow installs verified model resources and analyzes the PDF locally. Reopen cached results, copy or download figures, and export tables as HTML, TSV or Markdown.

Compare extracted content with the source pages, especially merged headers, footnotes and content crossing pages. Unresolved text and review warnings remain visible; extracted tables still require checking before analysis. [PDF extraction details](../guides/previews.md#pdf-extraction).

### Install packages into an external R environment

External R environments can now receive package-installation consent for an existing, writable personal R library. Select an eligible library and enable **Allow package install**. System and site libraries are excluded; consent can be revoked.

Where the required dependency locks exist, external R and Python environments can also provide conditional package-restoration evidence. Restoration requires matching prerequisites and a user-run restore script. Restoring packages does not by itself prove that research results reproduce. [R installation and restore conditions](../guides/runtimes.md#external-r-packages).

## Improvements and fixes

| Area | What changed |
| --- | --- |
| Codex Side Chat | Removed the old desktop guard that blocked the entry when the global provider used a Codex subscription. Session-state and recovery conditions can still make the entry unavailable. [Details](https://github.com/aipoch/open-science/pull/2460) |
| Connectors | Settings supports bulk enable/disable. Literature Graph adds Crossref work/update lookups and DataCite record/search methods; Rfam sequence search uses the repaired batch endpoint. [Management](https://github.com/aipoch/open-science/pull/2507), [data methods](https://github.com/aipoch/open-science/pull/2509) |
| CLI and SDK | Added runtime listing/installation, terminal profile initialization and Codex first-run setup. These extend the existing application-backed CLI. [Runtimes](https://github.com/aipoch/open-science/pull/2489), [initialization](https://github.com/aipoch/open-science/pull/2474), [Codex setup](https://github.com/aipoch/open-science/pull/2487) |
| Task downloads | Preserves the artifact's version identity and repairs a cause of HTTP 500 when downloading a completed task's output. [Download fix](https://github.com/aipoch/open-science/pull/2490) |

Other changes improve startup, update retries, Windows operation recovery, literature metadata and scientific Skill handling. See the [official release](https://github.com/aipoch/open-science/releases/tag/v0.29.0) for the complete list.
