# Changelog · v0.28.0

Released September 11, 2026. This version adds checks that rerun a saved result's recorded procedure and compare the output. It also expands global search and makes remote media loading explicit.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.28.0) · [Changes since v0.27.0](https://github.com/aipoch/open-science/compare/v0.27.0...v0.28.0)

## New features

### Check whether a saved result reproduces

**Reproducibility** uses a captured file version's inputs, execution record and environment information to rerun its procedure in isolation. Inspect the required evidence before starting a check, then review each output's comparison result. Checks can cover one version or a batch of versions, and their records can be exported.

A completed run alone does not mean the outputs match. Missing evidence or unsupported operations can prevent a check. This feature checks captured versions; it does not replay an entire session. Starting a check requires the desktop interface, and large RDS/H5AD files are not loaded for content comparison. [Feature details](../guides/reproducibility.md).

### Search messages, files and literature together

Global search now includes projects, sessions, message text, uploaded and generated files, and Library records and collections. Filter by category and relevant fields, select a result to inspect its context, then open the matching message or file. Supported text-file contents are searchable; this does not imply full-text indexing of every binary format.

Grouped results load further matches within each category. The detail pane can stay open while you move between results. [Search changes](../guides/navigation.md).

### Update an app-managed Codex runtime

Agent settings distinguish the native Codex CLI version from the ACP adapter version. An older app-managed installation can receive an explicit update to the tested pair. Externally installed CLIs still require manual maintenance. Finish or stop tasks using the runtime before replacing it; this is separate from updating Open-Science itself. [Runtime update details](../guides/frameworks.md#update-codex).

### Try WSL2 Bash on Windows

Windows x64 gains an optional **WSL2 Bash Preview**. PowerShell remains the default. Using the preview requires explicit activation, matching assets and successful readiness checks; it is not a prerequisite for ordinary Windows use. [Preview scope](../guides/runtimes.md#wsl2-preview).

## Changes that affect existing setups

| Area | What to expect |
| --- | --- |
| Remote model connections | Remote endpoints require HTTPS. Existing remote HTTP configurations remain editable but cannot run until corrected. HTTP remains supported for localhost and loopback addresses. |
| Media in responses | Remote images, audio and video wait for activation. Inspect the destination hosts before loading; authorization applies to that displayed element. |
| Images sent to a model | Model-input copies have ancillary metadata removed; the original files are preserved. |

These changes also apply when viewing or reusing older messages. [Connection and media changes](https://github.com/aipoch/open-science/pull/2420).

Configured Conda, PyPI and CRAN mirror hosts are temporarily authorized for the package-management operation. This does not add permanent Notebook permissions or automatically authorize redirects to other hosts. It also does not resolve an unavailable mirror or an invalid DNS response. [Package mirror changes](../guides/network.md).

## Improvements and fixes

Updates improve installer verification and retry behavior. Other fixes cover Windows R startup, PubMed metadata, session persistence and failure recovery. Check the [official release](https://github.com/aipoch/open-science/releases/tag/v0.28.0) for the complete list.

For installation, see [Install and update](../guides/installation.md). Continue to [v0.29.0](./v0.29.0.md), or review [v0.27.0](./v0.27.0.md).
