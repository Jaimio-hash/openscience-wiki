# Changelog · v0.30.0

Released September 15, 2026. This update adds tools for organizing reading and parallel discussions, and makes settings and extracted PDF evidence easier to reach.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.30.0) · [Changes since v0.29.0](https://github.com/aipoch/open-science/compare/v0.29.0...v0.30.0)

## New and updated workflows

| Feature | How to use it |
| --- | --- |
| Private bookmarks | Select conversation or preview text, or a PDF region, choose **For me**, and save a bookmark with an optional note. Return through **Bookmarks** in the session. These notes do not enter agent context. [Reading bookmarks](../guides/bookmarks.md) |
| Independent Side Chat tabs | Keep several discussions open beside Main. Move annotations into the intended draft before sending. Confirming **Close Side chat** stops that chat and permanently deletes its saved conversation. [Side Chat](../guides/delegation.md) |
| Settings center | Find panels under **Intelligence**, **Connections**, **Workspace** and **System**, or use the header search to navigate to a panel. [Settings overview](../settings/overview.md) |
| Global search | Open **Advanced filters** beside the categories to adjust scope, order, time and result-specific filters. Collapsing that column keeps the filters applied. [Navigation and search](../guides/navigation.md) |
| Extracted PDF evidence | Link the PDF and analyze it in **Figures and tables**. The agent can then list and read cached figures, tables and algorithms. [PDF evidence](../guides/previews.md#pdf-agent-evidence) |
| Provider catalog | SenseNova offers **China** and **Global** regions. Curated free gateway entries are available where the framework and account support them. [Provider setup](../guides/providers.md#provider-regions) |

## Improvements and fixes

- Session hover details include the session number; Skill, Connector and Specialist batch controls use a consistent action area.
- PDF fixes improve native figure/table recovery and text selection on rotated pages. Extraction still needs checking against the source.
- Connector fixes preserve dbSNP deletion alleles, correct VEP allele handling and unique-transcript counts, and repair excluded BioMart boolean filters.
- Idle background work is reduced. Update progress, runtime-recovery messages, Windows shell handling, result delivery and application shutdown receive reliability fixes.

## Before using the new workflows

Bookmarks remain within one session and are excluded from `.science` exports and cross-machine synchronization. Imported research packages remain read-only. Reproducibility still checks a selected saved version; it does not replay an entire session. See [research packages](../guides/research-packages.md) and [reproducibility](../guides/reproducibility.md) for the applicable workflow.

Use [Install and update](../guides/installation.md) to update the app. Earlier changes remain in [v0.29.0](./v0.29.0.md).

Continue to [v0.30.1](./v0.30.1.md) for the next release.
